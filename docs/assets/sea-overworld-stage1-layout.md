## 1. 构图结论

全图统一为“左上出征、北南分线、右上汇合”的战役构图：

- A 区是唯一大陆起点，视觉密度最高，主城与军港形成文明重心。
- 北线通过 A/B 接缝的碎岛链进入红湾卫所，再沿斜向防御纵深抵达右上南澳商港。
- 南线从 A 区西南近海进入 C 区危险外海，经灯塔、海寨、沙洲与古礁进入 D 区群岛战场。
- D 区通过月牙港和北向碎岛开口重新接入 B 区，最终与北线在南澳商港汇合。
- 全图中央十字区域使用两条斜向碎岛链建立视觉联系，但保留宽阔交叉水门，不放大型岛屿阻塞航行。

目标密度为 A 8/10、B 7/10、C 4/10、D 6/10；中央连接区维持 3/10，以小岛和礁石提供信息而不是填满海面。

## 3. 接缝设计

| 接缝 | 灰模处理 | 航行约束 |
|---|---|---|
| A/B，`x ≈ 2388` | 东湾水寨以东的碎岛在 B 区继续指向红湾卫所 | 小岛不封口，保留一条宽阔北线主航道 |
| A/C，`y ≈ 1292` | 川山渔村、青屿秘境下方以稀疏暗礁延续到澄海灯岛 | 保留大陆南侧进入 C 区的明显水门 |
| B/D，`y ≈ 1292` | B 区下缘礁点与 D 区月环商港北侧岛链形成向上开口 | 南线必须能由 D 区自然回到南澳商港 |
| C/D，`x ≈ 2388` | 玄潮古屿的破碎礁群跨缝延续到雾岚群岛西缘 | 形成视觉连续但不使用连续碰撞墙 |

四区中央交点附近不得放大型可进入岛。交点至少保留约 480 世界单位宽的连续水域，使东西、南北航向都能通过。

## 4. D 区航道灰模

1. 宽阔主航道：位于雾岚群岛和伏波古岭之间，最直观、最易辨认。
2. 狭窄礁峡：位于沧门礁堡和月环商港之间，距离短但视觉压力较强。
3. 南部绕行航道：沿珊湾渔链外侧通过，路线最长、留白最充足。

阶段一只通过岛屿轮廓和水面负空间表现差异，不加入流速、伤害、封锁或数值规则。
