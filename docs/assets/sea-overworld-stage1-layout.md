## 1. 构图结论

全图统一为“左上出征、北南分线、右下汇合”的战役构图：

- A 区是唯一大陆起点，视觉密度最高，主城与军港形成文明重心。
- 北线通过 A/B 接缝进入 B 区群岛水战场，经沧门礁堡、雾岚群岛与月环商港向南进入 D 区。
- 南线从 A 区西南近海进入 C 区危险外海，经灯塔、海寨、沙洲与古礁直接进入 D 区。
- D 区以红湾卫所、东极秘岛和南澳商港形成由左上向右下推进的敌方防御纵深，两线在此汇合。
- 全图中央十字区域使用两条斜向碎岛链建立视觉联系，但保留宽阔交叉水门，不放大型岛屿阻塞航行。

目标密度为 A 8/10、B 6/10、C 4/10、D 7/10；中央连接区维持 3/10，以小岛和礁石提供信息而不是填满海面。

v4 沿用 v3 的功能造型与南北海域差异，只将沧门礁堡从右上建筑密集区迁到中央偏右的 B 区水面，形成北线门户并缩小中央空洞。右上以月环商港为主地标、伏波古岭为次地标；中央沉船、微型礁石和十字通航水门保持不变。

四区中央交点附近不得放大型终点岛。v4 允许中型沧门礁堡位于交点东北侧，但堡垒与沉船、自然山岛之间至少留出约 480 世界单位的连续水域，使东西、南北航向都能通过。

## 4. B 区航道灰模

1. 宽阔主航道：位于雾岚群岛和伏波古岭之间，最直观、最易辨认。
2. 狭窄礁峡：位于中央偏右的沧门礁堡和月环商港之间，作为北线进入中央水门的短程高压入口。
3. 外侧绕行航道：沿伏波古岭东侧和珊湾渔链外缘通过，路线最长、留白最充足。

阶段一只通过岛屿轮廓和水面负空间表现差异，不加入流速、伤害、封锁或数值规则。
