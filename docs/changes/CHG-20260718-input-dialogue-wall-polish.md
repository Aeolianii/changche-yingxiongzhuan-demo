# CHG-20260718-input-dialogue-wall-polish

- Status: completed
- Type: feature + fix
- Owner: Codex
- Created: 2026-07-18

## 目标

改善场景一的直接操作体验：缩小并下移对话框；支持键盘移动；让空格键完成剧情交互；使墙体碰撞与宫殿图形对齐。

## 范围

- 缩小、下移纸张对话框，并同步调整文字和继续按钮。
- 支持 WASD 与方向键移动。
- 空格键按照当前剧情状态执行“继续”“对话”或“觐见”。
- 复查外墙、殿内隔墙、御座和中央门洞碰撞。

## 非目标

- 不改变剧情文本、角色素材和自动带路流程。
- 不加入寻路网格或高度系统。

## 验收结果

- [x] 对话框位于屏幕下部，尺寸明显缩小，不再大面积遮挡中央人物。
- [x] WASD 和方向键均可控制主角移动。
- [x] 空格键可推进旁白、触发对话、触发觐见并结束场景。
- [x] 玩家不能穿过外墙、殿内左右隔墙和御座区域。
- [x] 玩家可以从中央门洞双向通行。
- [x] 指定场景当前运行日志无错误和警告。

## 实现说明

- UI 继续使用现有 Paper UI 素材，没有生成新图。
- 空格和 E 共用 `interact` 输入动作，鼠标按钮仍然保留。
- 墙体继续使用场景中的 `CollisionPolygon2D`，通过可见碰撞层进行复核。
- 补充了 Godot 4.7 可正确识别的 Left/Right 方向键绑定。

## 验证证据

- Godot 4.7 中完整执行八个剧情状态，全部可由空格键推进。
- A 键、Right 和 Up 方向键均已注入实测。
- 左侧世界边界阻挡位置约为 `x=67`。
- 左侧殿墙从院外向上测试，阻挡位置约为 `y=625`。
- 中央门洞从 `x=768` 可正常进入殿内。
- 当前游戏日志只有调试助手注册信息，无游戏错误和警告。

## 最终对账

- 变更文件：`scenes/palace/palace_demo.tscn`、`scripts/palace_demo.gd`、`project.godot`，以及关联的设计、架构和 QA 文档。
- 已知限制：皇帝和太监仍使用临时角色素材；自动带路期间会按设计锁定玩家输入。
