# CHG-20260718-manual-palace-objective

- Status: done
- Type: gameplay + UI
- Owner: Codex
- Created: 2026-07-18

## 目标与玩家体验

把场景一从“脚本强制带路”改为“任务指引 + 玩家自行行走”。玩家看完开场急报后，先接近太监完成传召，再根据“奉诏入殿”任务自行穿过中央门洞进入正殿。

## 范围

- 新增常驻但不遮挡视野的任务指引 UI。
- 太监到达殿外后，玩家接近才出现“对话”交互。
- 任务措辞采用古风语境：“阅看岭南急报”“听取内侍传召”“奉诏入殿”“聆听圣谕”“领旨南下”。
- 玩家接近皇帝后出现“觐见”交互。
- 删除水师主帅自动入殿与剧情阶段移动锁定。
- 保留太监自身的脚本移动。

## 非目标

- 不加入箭头寻路、导航网格、小地图或任务列表系统。
- 不改正式对白、角色素材、场景背景和墙体碰撞。
- 不要求玩家在对话时完全静止。

## 验收条件

- [x] 主角从场景开始到结束始终可以使用 WASD/方向键移动。
- [x] 太监未进入交互距离时不显示“对话”按钮，接近后显示。
- [x] 传召完成后任务指引显示“奉诏入殿”。
- [x] 玩家必须自行穿过中央门洞进入正殿。
- [x] 未接近皇帝时不显示“觐见”，接近后显示。
- [x] 任务在完成觐见后更新为“领旨南下”。
- [x] 鼠标和空格键交互均可用，运行日志无错误。

## 验证证据

- Godot 4.7 指定场景 run 10：开场状态 `controls_enabled=true`。
- 玩家位于 `(1200, 850)`、太监位于 `(710, 832)` 时，“对话”不可见；玩家移动到太监约 52 像素内后显示“对话”。
- 传召后等待 2 秒，玩家坐标保持 `(768, 700)`，证明剧情没有自动移动主帅；太监可独立返回殿内。
- 玩家自行沿中央门洞向上移动至皇帝约 10 像素处后显示“觐见”。
- 空格键完成觐见、两段正式对白、圣旨与收尾，任务最终显示“领旨南下”。
- 当前游戏日志无错误或警告。

## 最终对账

- 场景新增 `TaskPanel/TaskText` 任务栏。
- `palace_demo.gd` 删除主帅自动入殿和输入锁定，新增距离交互与任务文本投影。
- 已知限制：目前只有文字任务栏，没有方向箭头或路径提示；这是本次明确的非目标。
