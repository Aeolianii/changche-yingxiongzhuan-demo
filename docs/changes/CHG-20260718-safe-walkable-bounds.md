# CHG-20260718-safe-walkable-bounds

- Status: done
- Type: collision fix
- Owner: Codex
- Created: 2026-07-18

## 目标与玩家体验

把皇宫原型的活动范围收进画面中央安全区域，避免玩家走到最右侧、最下侧或装饰边缘形成难以脱离的角落。碰撞只需与庭院视觉大致一致，优先保证顺畅，不追求逐物件精确描边。

## 范围

- 将庭院左右活动边界向画面内收。
- 将庭院底部活动边界上移到石像上方附近。
- 保留左右庭院、中央御道和中央门洞为连通区域。
- 保留正殿内部、御座和殿墙现有规则。

## 非目标

- 不给旗帜、树木、石灯和花坛逐个添加碰撞。
- 不增加导航网格或程序生成碰撞。
- 不修改背景图片和角色脚底碰撞。

## 计划边界

- 左侧安全边界约 `x=176`。
- 右侧安全边界约 `x=1360`。
- 庭院底部安全边界约 `y=900`。
- 殿墙与庭院分隔继续使用 `y=615`，中央 `x=640..900` 门洞保持开放。

## 验收条件

- [x] 玩家不能进入最右侧贴图边缘。
- [x] 玩家不能走到庭院最下方石像与画面边缘之间。
- [x] 玩家抵达右下角后，向左、向上和左上方向均能脱离。
- [x] 左右庭院与中央御道保持连通。
- [x] 中央门洞仍可双向通行。
- [x] 可见碰撞显示与安全活动区大致一致。
- [x] 当前运行日志无错误或警告。

## 验证证据

- Godot 4.7 指定场景 run 12，开启可见碰撞层检查。
- 向右持续移动后停在 `x≈1351`，向下持续移动后停在 `y≈900`。
- 从右下角 `(1350, 899)` 脱离测试：
  - 向左到达 `(1299, 900)`。
  - 向上到达 `(1350, 846)`。
  - 左上到达 `(1305, 863)`。
- 从右庭院 `x=1300` 向左持续移动，可穿过中央御道并到达左边界 `x≈185`。
- 从 `(768, 700)` 向上移动可穿过中央门洞，到达殿内 `y≈280`。
- 当前运行日志只有调试助手注册信息，无游戏错误或警告。

## 最终对账

- 修改 `LeftWall`、`RightWall` 和 `BottomGate` 三个编辑器可见碰撞多边形。
- 未给装饰物添加独立碰撞，保持本次“连续安全范围优先”的设计。
- 已知限制：边界是原型级近似范围，后续背景美术定稿后仍可在 Godot 编辑器中拖动顶点微调。
