# CHG-20260718-upper-hall-safe-bounds

- Status: done
- Type: collision fix
- Owner: Codex
- Created: 2026-07-18

## 目标与玩家体验

为上方正殿增加与庭院相同思路的内缩安全活动区。人物只能在中央地砖区域与御道上行走，不能贴到顶部陈设、左右墙边或下方屋顶墙檐。

## 范围

- 将正殿顶部活动边界下移。
- 将正殿左右活动边界进一步向内收，但不影响下方庭院宽度。
- 将左右殿墙碰撞向上扩展，使人物在屋顶/墙檐之前停下。
- 保持中央门洞、皇帝交互位置和太监路线可用。

## 非目标

- 不给屏风、香炉、地毯和柜子逐个描碰撞。
- 不修改庭院安全范围、背景图片和角色碰撞。
- 不改变剧情与任务状态。

## 计划边界

- 正殿顶部安全边界约 `y=190`。
- 正殿底部安全边界约 `y=440`。
- 正殿左右安全边界约 `x=280..1256`。
- 中央门洞继续保持 `x=640..900`。
- 正殿左右内缩使用独立矩形碰撞，不与庭院边界合并成凹多边形，避免 Godot 自动分解产生斜向碰撞。

## 验收条件

- [x] 人物不能站到下方屋顶/墙檐上。
- [x] 人物不能进入顶部陈设区。
- [x] 人物不能贴到正殿最左、最右侧装饰区。
- [x] 正殿四角均可向中央方向脱离。
- [x] 中央门洞仍可双向通行。
- [x] 玩家仍可接近皇帝触发“觐见”。
- [x] 当前运行日志无错误或警告。

## 验证证据

- Godot 4.7 指定场景 run 16，开启可见碰撞层检查。
- 正殿边界实测：
  - 顶部停止于 `y≈200`。
  - 下方墙檐前停止于 `y≈440`，不再停在原来的 `y≈485` 屋顶线上。
  - 左侧停止于 `x≈289`。
  - 右侧停止于 `x≈1247`。
- 四角朝中央斜向移动均能脱离：
  - 左上到 `(339, 239)`。
  - 右上到 `(1199, 237)`。
  - 左下到 `(339, 401)`。
  - 右下到 `(1197, 401)`。
- 中央门洞向上可到 `(768, 280)`，向下可到 `(768, 749)`。
- 玩家在皇帝约 10 像素内仍显示“觐见”。
- 当前运行日志只有调试助手注册信息，无游戏错误或警告。

## 最终对账

- `TopPalace` 下边界调整至 `y=190`。
- `HallWallLeft`、`HallWallRight` 上边界调整至 `y=440`。
- 新增 `UpperHallLeftSafe`、`UpperHallRightSafe` 两个独立矩形碰撞。
- 验证过程中否决了凹多边形方案，因为可见碰撞显示其自动分解出斜向三角形；最终版本没有该隐形斜边。
- 已知限制：仍是原型级近似边界，背景定稿后可以继续拖动矩形顶点微调。
