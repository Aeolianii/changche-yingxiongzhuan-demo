# CHG-20260807 第二章对话巡视流程

- Status: done
- Owner: Codex
- Updated: 2026-08-07

## 目标

用 NPC 对话完成第二章“巡视水师驻地”的剧情推进，不加入环境调查交互；明确区分中军军官与广州县令，并让县令会谈成为水师操练的唯一剧情入口。

## 流程

1. 副将迎接结束，任务提示与两名甲板值守士兵交谈。
2. 玩家可按任意顺序听取左、右值守士兵的巡视汇报；重复交谈不重复累计。
3. 两份汇报齐全后，任务提示向中军军官复命。
4. 完成复命对白后，“巡视水师驻地”完成，新任务更新为“筹备水师操练”。
5. 玩家与广州县令单独会谈，县令与主帅商议军需后开启既有操练演示。

## 非目标

- 不增加船炮、桅杆、船舷或其他环境调查点。
- 不实现通用存档、任务数据库或跨章节任务序列化。
- 不重做操练演出内容。

## 验收标准

1. 中军军官和广州县令是两个独立 NPC，姓名、对白和任务职责不混用。
2. 未完成两名士兵对话时，军官不会接受复命，县令不会开启操练。
3. 两名士兵可以任意顺序交谈，每人只计入一次进度。
4. 军官复命对白结束后，“巡视水师驻地”标记完成并切换至“筹备水师操练”。
5. 只有随后与县令完成会谈，才进入既有操练界面。
6. HUD 与任务详情同步显示当前对话目标和已完成步骤。
