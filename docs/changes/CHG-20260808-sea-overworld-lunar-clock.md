# CHG-20260808 海上大地图月相时钟

- 状态：done

## 目标

将海上大地图左上角原海图入口区域改为月相时钟，以连续月相变化表达长达一至两个月的航行时间；海图入口缩小后固定在右下角。

## 范围

- 为海上大地图 HUD 增加水墨像素风月面组件和菱形月相时钟。
- 船只实际移动时每 2 秒推进 1 个游戏日，29.5 个游戏日完成一个朔望月。
- 月面从新月连续变化至满月，并继续完成亏月周期；阶段名称随月相更新。
- 月相进度在海上大地图与场景二往返期间保留，本次运行结束后不持久化。
- 将可点击海图菱形入口缩小并锚定在右下角，完整海图交互保持不变。
- 船只完成实际物理位移后发出航行信号，由大地图据此推进月相，避免静止、碰撞或阻断界面期间误计时。

## 非目标

- 不增加昼夜光照、天气、潮汐、补给或船员消耗。
- 不把月相接入剧情门控、战斗数值或正式存档。
- 不修改地点、事件、碰撞和海图内容。

## 验收检查

1. 大地图左上显示菱形月相时钟，不再显示海图图标。
2. 船只静止、菜单或完整海图打开时月相不推进；正常航行时按时间倍率推进。
3. 新月、上弦、满月、下弦等阶段的视觉遮罩与名称对应。
4. 右下角小型海图入口可点击，仍能打开并关闭完整海图。
5. 月面 PNG 具有透明外角、无生成文字，并使用最近邻采样。
