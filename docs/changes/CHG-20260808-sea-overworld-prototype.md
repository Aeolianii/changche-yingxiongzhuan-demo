# CHG-20260808 海上大地图初版

## 目标

实现一套独立可运行的轻量海上大地图原型，用于验证船只移动、地点接近提示、进入占位提示及海上自动触发。

## 完成内容

- 新增广东海岸原型海上大地图场景。
- 使用WASD和方向键控制Q版主角船只移动，不支持鼠标点击海面移动。
- 航行时切换船只移动状态，显示4帧尾浪、侧浪和轻微浮动。
- 海上大地图复用场景一、场景二的共享探索HUD，显示相同的主角状态栏、任务栏、任务界面、五个功能入口和系统菜单；删除原型专用标题、操作说明和独立提示框。
- 海图主线改为“探索大地图”，按航行、靠近海岛、尝试进入和触发海上目标四个步骤推进；支线占位改为“海上见闻”。
- 为主要岛屿和海岸增加手工碰撞，避免船只直接穿过地点。
- 靠近地点时显示地点名称、底部“进入”按钮和按E提示，不绘制岛屿轮廓或环形高亮。
- 点击“进入”或按E显示“该地点即将开放”，不切换场景。
- 接触渔船、商船和漂流木箱时自动显示对应“开发中”提示。
- 自动触发依赖 `Area2D.body_entered`，同一次停留不会逐帧重复弹出，驶离后可以再次触发。
- 新增运行测试和有窗口预览截图流程。

## 当前边界

- 不修改正式主场景入口。
- 不接入皇宫、水师驻地或章节状态机。
- 不实现岛屿小地图、剧情、海战、快速移动、风向、洋流和航海资源。
