# CHG-20260808 D 区海水颜色匹配

- 状态：已完成

## 目标

将 D 区偏浅、偏亮的海水匹配到相邻 B/C 区的蓝青色域，同时保证岛屿、建筑、植被、沙滩、礁石、附岛和障碍物颜色不变。

## 实现

- 以 D 区原图、C 区与 B 区海图调用内置生图编辑，确认目标海色约为 RGB `(5, 172, 222)`。
- 从 `guangdong_sea_zone_d_v1.png` 另存 `guangdong_sea_zone_d_v2.png`，仅对符合海水色域的像素应用通道偏移 `(+5, -10, -22)`。
- 受限蒙版外的 1,025,952 个像素逐字节不变；五座岛屿复合体与障碍礁群的代表采样点均与原图完全一致。
- `sea_overworld.gd`、`sea_overworld.tscn` 和完整海图界面统一切换到 v2 素材。

## 验收

1. D 区受校正海水平均色约为 RGB `(6, 171, 222)`，与 B/C 区约 RGB `(4–9, 171–172, 222)` 的范围一致。
2. 所有蒙版外像素与 v1 完全一致，岛屿和障碍物未重绘、未移动、未改色。
3. D 区仍为 3344×1882，场景坐标、交互入口、碰撞和接缝配置不变。
4. 海上大地图针对性运行验证通过。
