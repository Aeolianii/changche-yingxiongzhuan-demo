# CHG-20260808 海上大地图 D 区扩展

- 状态：已完成

## 目标

在 B 区正下方、C 区右侧接入 D 东南海域，完成海上大地图的 A/B/C/D 二乘二结构。D 区包含五个可进入主岛、附岛与礁石轮廓，以及不提供登陆入口的小型航行障碍群。

## 范围

- 使用 Codex 内置生图工具生成 3344×1882 的 D 区水墨像素海图。
- 五个可进入地点：沧门礁堡、月环商港、雾岚群岛、伏波古岭、珊湾渔链。
- 左侧两岛靠近 C/D 接缝后的西部海域，右侧两岛与其拉开形成宽阔纵向航道，最下方链状渔岛保持独立位置。
- 岛屿轮廓不局限于圆形单岛；雾岚群岛、月环商港与珊湾渔链使用主岛、附岛、礁石或链状组合。
- 右侧设置小型岩礁障碍，仅提供碰撞，不注册地点入口或完整海图标签。
- D 顶部与 B、左侧与 C 分别使用 120 世界像素重叠带，并同时进行横向与纵向 Alpha 融合。
- `World/DBackground` 序列化进入 `sea_overworld.tscn`，使 Godot 2D 编辑器直接显示 D 区。
- 五个地点点击或按 E 后统一显示“该岛屿即将开放”。

## 非目标

- 不制作五岛内部场景、剧情、商店、战斗或正式转场。
- 障碍礁石不显示地点名称、不提供交互入口。
- 不新增风向、洋流、补给、区域解锁或海战系统。

## 验收检查

1. A/B 在上、C/D 在下组成完整二乘二海图，四条相邻接缝无空白或明显硬边。
2. D 区恰好五个可进入地点，岛屿间距不完全相同且保留可航行水道。
3. 左右两组岛屿之间有宽阔纵向航道，最下方链状岛保持独立。
4. 至少两座主岛具有附岛、礁石或非圆形延伸；小型障碍群不可登陆。
5. 五个地点均显示“该岛屿即将开放”。
6. `sea_overworld.tscn` 中存在且仅存在一个 `World/DBackground`。
