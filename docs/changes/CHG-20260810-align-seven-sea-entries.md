# CHG-20260810 七处海图入口对位

- 状态：done
- 类型：地图内容 / 交互 / UI
- 日期：2026-08-10

## 目标

按生产地图中可见的码头、洞口和岛屿碰撞轮廓，重新对齐七处地点交互范围，并将“南澳商港”更名为“倭寇营地”。

## 范围

- 澄海灯岛：入口覆盖碰撞轮廓周围一圈。
- 倭寇营地：名称替换原“南澳商港”，入口移动到城塞下方主码头。
- 红湾卫所：入口移动到右下山洞口。
- 珊湾渔链：保留原入口并增加左下入口。
- 伏波古岭：保留原入口并增加右下入口。
- 雾岚群岛、东湾水寨：入口分别移动到各自岛屿下方码头。
- 更新完整海图名称、区域地点契约和针对性入口测试。

## 非目标

- 不修改用户在 `World/WorldCollision` 下手工编辑的碰撞轮廓或层级。
- 不移动背景岛屿、玩家出生点、其他地点、NPC 船只或随机事件。
- 不实现地点小地图或新的进入流程。

## 验收检查

1. 七处入口中心均落在可航行水面并能显示正确地点提示。
2. 澄海灯岛可从碰撞体四周触发；珊湾渔链和伏波古岭新增方向可触发。
3. 倭寇营地、雾岚群岛、东湾水寨只使用对应码头附近的入口；红湾卫所使用右下洞口入口。
4. 完整海图显示“倭寇营地”，不再显示“南澳商港”。
5. `tests/test_sea_overworld.gd` 的入口与命名验证通过；若用户当前碰撞仍有独立失败，记录并区分于本次入口改动。
