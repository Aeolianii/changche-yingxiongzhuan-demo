# CHG-20260810 川山渔村码头与海图标签校正

- 状态：进行中
- 类型：交互 / UI
- 日期：2026-08-10

## 目标

按用户截图中的红色当前位置标记，精确校正川山渔村的小码头交互点，并把完整海图中的“川山渔村”标签上移到大陆房屋区。

## 范围

- 将截图红点与当前完整海图进行像素对齐，使用其对应世界坐标约 `(1470,680)` 作为川山渔村唯一入口中心。
- 将川山渔村入口由大片下方矩形水面改为小码头处的紧凑圆形触发区。
- 保持川山渔村地点中心 `(1080,650)` 不变，仅通过海图标签偏移把名称上移到陆地房屋上。
- 更新入口坐标、标签位置和可航水面自动验证，并完成 Vulkan 海图截图复核。

## 非目标

- 不再交换地点，不改变南海军港、出生点或半圆港湾交互区。
- 不重绘 A 区背景，不修改大陆海岸碰撞。
- 不调整东湾水寨及其他地点标签。

## 验收检查

1. 川山渔村交互中心位于截图红点对应的小码头 `(1470,680)`。
2. 该点位于玩家船只可达水面，能够显示“川山渔村”入口提示。
3. 完整海图中的“川山渔村”上移到陆地房屋区，不再压在下方水面和当前位置标记附近。
4. 南海军港半圆交互、出生和场景二往返保持不变。
5. `tests/test_sea_overworld.gd` 通过并完成 Vulkan 截图复核。
