# CHG-20260810 海域迷雾与海图探索

- 状态：in-progress
- 类型：海图探索 / 剧情 / 任务 / 存档
- 日期：2026-08-10

## 目标

让岭南海图从“全图已知”改为“从南海军港出发逐步勘明”：新游戏只点亮南海军港周边，玩家航行经过的视野范围永久揭示，并在航行场景与完整海图中同步显示。首次县令会谈补充水师久疏操练、沿海海情未明的动机，操练后的主线任务统一为“探索海域，完善海图”。

## 范围

- 海上大地图增加黑色两态迷雾：未探索为黑，已探索永久点亮。
- 视野尺寸从当前 `Camera2D` 可见世界范围计算，地图缩放后无需手工调整固定半径。
- 初始只揭示南海军港出生点周边；航行时按位图网格增量揭示。
- 完整海图复用同一探索位图，未探索地点不显示名称，玩家当前位置始终显示。
- 迷雾进度跨海图/场景二往返保留，并随正式单槽存档保存；旧存档缺少该字段时回退到军港初始揭示。
- 新游戏只重置本次运行的海图探索状态，不删除或覆盖磁盘旧存档。
- 首次县令会谈加入海情未明与出海巡视说明；第二次及以后县令对话、选项和出海流程保持现状。
- 场景二操练后、海上任务栏和任务界面统一显示“探索海域，完善海图”。

## 非目标

- 不实现会重新闭合的动态视野、敌我单位可见性、天气浓雾或航行减速。
- 不改变海岸与岛礁碰撞、地点坐标、场景入口或海战玩法。
- 不要求本次把海图探索到 100% 后结算奖励或推进新章节。
- 不修改用户当前未提交的海图碰撞场景调整。

## 验收检查

1. 新游戏进入海图后，南海军港附近已点亮，远端海域保持全黑。
2. 点亮范围与当前相机可见世界尺寸同步，船只航行后留下永久可见航迹。
3. 航行画面与完整海图使用相同探索数据；未探索地点名称隐藏，军港和玩家当前位置可见。
4. 返回场景二再出海、保存读取后，已经揭示的海域不丢失。
5. 旧版无迷雾字段存档可读取，并从军港初始揭示开始。
6. 首次县令会谈说明水师久疏操练、海情未明和巡视海域；后续县令出海询问与两项选择不变。
7. 任务栏与任务界面均显示“探索海域，完善海图”。
