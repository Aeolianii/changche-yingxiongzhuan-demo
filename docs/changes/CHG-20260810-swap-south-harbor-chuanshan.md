# CHG-20260810 南海军港与川山渔村位置交换

- 状态：进行中
- 类型：地图内容 / 交互 / UI
- 日期：2026-08-10

## 目标

交换 A 区南海军港与川山渔村的地点身份，使南海军港落在西南侧半圆港湾、川山渔村落在东北侧大陆码头，并同步调整出生点、入口范围和完整海图标注。

## 范围

- 南海军港由 `(1080,650)` 迁至 `(480,1040)`，在半圆港湾内部沿弧线布置多个连续交互区。
- 场景二进入海上大地图和直接启动大地图时，玩家统一出生在半圆港湾内部并处于南海军港交互范围。
- 川山渔村由 `(480,1040)` 迁至 `(1080,650)`，入口位于大陆聚落下方码头水面。
- 完整海图中的两处地名跟随地点交换。
- 将“岭 南 海 图”标题在卷轴牌匾内继续下移。
- 更新地点、出生点、场景往返和海图 UI 的针对性验证。

## 非目标

- 不重绘 A 区背景，不移动海岸、港湾、码头或静态碰撞。
- 不改动其他 13 个地点、四区数量、主流程返回语义或加载文案。
- 不调整任务、月相、存档格式和船只移动规则。

## 验收检查

1. 南海军港位于西南半圆港湾，入口由港湾内沿弧线分布的多个触发区组成。
2. 新开大地图及从场景二进入时，玩家出生在半圆港湾内、位于可航水面，并立即显示南海军港入口提示。
3. 川山渔村位于东北侧大陆聚落，下方码头水面可以触发入口提示。
4. 完整海图中南海军港和川山渔村的名称已交换，其他地点名称不变。
5. “岭 南 海 图”标题继续下移且仍位于顶部牌匾内。
6. `tests/test_sea_overworld.gd` 与 `tests/test_scene_two_sea_link.gd` 通过，并完成完整海图截图复核。
