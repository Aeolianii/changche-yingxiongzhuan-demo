# CHG-20260810 玄潮古屿入口与海图标注优化

- 状态：已完成
- 类型：交互 / UI
- 日期：2026-08-10

## 目标

让玄潮古屿的地点交互和完整海图标注与右下角破碎礁群的实际画面一致，并确保白沙渔岛南侧码头水面可以触发地点交互。

## 范围

- 将完整海图中的“玄潮古屿”标签移到礁群右下方。
- 将玄潮古屿入口拆为礁群北侧、南侧和东侧三个独立近岸水面触发区，不在西侧设置入口，避免与白沙渔岛的入口方向混淆。
- 保留并校准白沙渔岛南侧码头水面的入口触发区。
- 增加针对三个玄潮入口方向、玄潮标签偏移和白沙码头入口的自动验证。

## 非目标

- 不重绘 C 区背景、礁石或白沙渔岛。
- 不移动地点中心，不改名，不改变四区地点数量。
- 不修改静态礁石碰撞、航线、进入后的占位反馈或其他地点入口。

## 验收检查

1. “玄潮古屿”在完整海图中显示于破碎礁群右下方，并与白沙渔岛标签拉开。
2. 船只可从玄潮礁群北侧、南侧和东侧触发“玄潮古屿”，西侧不触发。
3. 船只可在白沙渔岛南侧码头水面触发“白沙渔岛”。
4. 三个玄潮入口和白沙码头入口均位于无静态阻挡、船只可达的水面。
5. `tests/test_sea_overworld.gd` 通过，完整海图截图显示标签位置正确。

## 文档影响

- 更新 `docs/assets/sea-overworld-stage1-layout.md` 的 C 区最终入口方向与海图标签约束。
- `docs/design/sea-overworld-design.md` 的通用地点交互流程不变。
