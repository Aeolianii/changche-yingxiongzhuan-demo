# CHG-20260812 大地图过场隐藏探索 HUD

- 状态：in-progress
- 日期：2026-08-12

## 目标

修复从 Scene2 与广州县令对话并选择“立即出发”后，进入大地图的加载过场错误显示探索 HUD（任务栏与顶部功能按钮）的问题。

## 范围

- Scene2 进入海上大地图的过场可见性状态。
- 县令出发链路的自动化回归断言与加载中截图。
- 共享 HUD 与场景加载过场的架构约束。

## 非目标

- 不改动加载图、美术布局、加载时长或大地图 UI 的正常显示。
- 不改动迷雾、海上随机事件与大地图场景切换目标。

## 验收标准

- 点击县令“立即出发”后，加载过场显示期间共享探索 HUD 根节点不在场景树中可见。
- 过场中不显示左侧任务栏、顶部任务/人物/物品栏/船只/菜单按钮或海图入口。
- 进入大地图后探索 HUD 恢复，并保持大地图专属 UI 状态。
- Scene2 与大地图往返链路仍可运行。

## 文档影响

- `docs/tech/architecture.md`：补充过场期间共享 HUD 必须隐藏的约束。
- `docs/qa/playtest.md`：完成后记录过场截图和自动化验证。

## 预计改动

- `scripts/scene_2.gd`
- `tests/test_scene_two_sea_link.gd`

## 验证方式

- 运行 `tests/test_scene_two_sea_link.gd`。
- 在非 headless 模式抓取进入大地图后 0.25 秒的加载中截图并人工检查。
