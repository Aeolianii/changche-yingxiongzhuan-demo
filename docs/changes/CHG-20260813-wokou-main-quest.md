# CHG-20260813 倭寇大本营主线

## 目标

在海上大地图“探索海域，完善海图”主线中补齐倭寇大本营的接战剧情与当前版本的默认胜利收束。

## 实现

- 将终局地点显示名由“倭寇营地”明确为“倭寇大本营”。
- 舰队驶近大本营时自动触发士兵示警，确认后主线目标更新为进逼敌营。
- 玩家进入码头交互范围并按 E 后，由水师元帅先斥责海霸天，再切换到海霸天指定立绘及回话。
- 战斗选项明确标注战斗系统尚未完善、当前默认获胜。
- 默认胜利后播放四秒“靖海奏捷”占位 CG，并恢复航行控制。
- 警戒确认与默认胜利状态随海上事件状态、正式存档保存和恢复。

## 验证

- `tests/test_wokou_main_quest_flow.gd` 覆盖近域示警、主角先发言、海霸天立绘与口吻、默认胜利、CG 和状态持久化投影。
- `tests/test_sea_overworld_entry_alignment.gd` 覆盖更名后的大本营码头入口坐标。
- `tests/test_fubo_side_quest_flow.gd` 确认伏波古岭原支线流程未受影响。
