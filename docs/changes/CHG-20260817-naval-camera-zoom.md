# CHG-20260817 海战统一镜头与滚轮缩放

## 状态

已完成。

## 目标

自由关和随机遭遇不再用全图微缩视角开局。所有海战模式与第一关教程保持相同的初始棋子、格子尺度，并允许玩家按战况自行缩放。

## 修改

- 教学关、自由关、随机遭遇的布阵和正式战斗统一以 `3×` 倍率进入。
- 每次进入阶段时，镜头立即居中玩家指挥舰；无有效指挥舰时随机居中一艘我方存活舰，我方无可用舰船时才回退地图中心。
- 鼠标滚轮以指针位置为锚点按 `0.25×` 步进缩放，最近上限为 `4×`。
- 最远倍率按当前地图完整适配倍率的 `90%` 动态计算，完整棋盘外保留少量海面留白。
- 海面背景按最远倍率预留安全范围，缩放、WASD 平移与选船聚焦均继续受边界约束。

## 验收

- 自由关进入布阵及战斗时不再显示微缩棋盘，初始倍率与第一关一致。
- 初始镜头中心位于玩家指挥舰。
- 滚轮上下缩放可达动态最远值与 `4×` 最近值，并且不会露出背景边缘。
- 编译、海战场景冒烟测试和 OpenGL 实机截图通过。

## 验证结果

- `dotnet build --no-restore`：通过，0 警告、0 错误。
- `tests/test_naval_scene_smoke.gd`：通过，覆盖初始 `3×`、有/无指挥舰聚焦、`4×` 上限、动态最远倍率与背景边界。
- Godot 4.7.1 OpenGL `1344×896`：自由关初始画面确认居中我方舰；注入真实滚轮事件后倍率由 `3×` 增至 `3.25×`，截图正常。
