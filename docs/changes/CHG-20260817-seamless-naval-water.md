# CHG-20260817 海战动态海面去接缝

## 状态

已完成。

## 问题

海战背景的水波亮纹出现明显横向或矩形分割痕迹。源海面纹理本身不是严格无缝贴图，旧着色器又使用 `fract()` 将纹理边缘直接首尾相接，多层亮度提取进一步放大了边缘色差。

## 修改

- 动态海面所有纹理读取改为边界连续的镜像循环采样，消除原图边缘的硬跳变。
- 折射亮纹强度由 `0.24` 降至 `0.14`，保留水面动态但压低规则亮线。
- 增加海战场景冒烟断言，防止重新引入直接 `fract()` 纹理采样或过强亮纹。

## 验收

- 镜头平移、缩放和水面持续流动时，无固定横线、竖线或矩形拼接边。
- 海水仍保留缓慢流动的水墨明暗变化。
- 海战场景冒烟测试通过，并完成 OpenGL 实机截图检查。

## 验证结果

- `dotnet build --no-restore`：通过，0 警告、0 错误。
- `tests/test_naval_scene_smoke.gd`：通过。
- Godot 4.7.1 OpenGL `1344×896` 实机截图：动态海面无硬接缝，水墨流动与既有战争迷雾层正常保留。
