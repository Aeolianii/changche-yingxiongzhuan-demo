# CHG-20260817：劝降卡片与教程浮层避让

- 状态：`done`
- 日期：2026-08-17

## 目标

解决战斗劝降交涉卡片与新手教程墨条在顶部中央区域重叠的问题。

## 方案

- 劝降卡片显示时，将其作为高优先级临时决策层，暂停教程完整态、收起态墨签和切换入口。
- 劝降卡片关闭后恢复进入交涉前的教程展开/收起状态。
- 不修改教程步骤、完成进度、劝降规则和按钮交互。

## 验收

- 劝降卡片与教程浮层不会同时显示。
- 劝降关闭后教程状态正确恢复。
- 编译、教程专项测试和实机截图通过。
