# CHG-20260817 海战白色像素水墨迷雾

## 状态

已完成。

## 问题

旧战争迷雾按不可见格绘制半透明黑色矩形，形成规则方块墙，与青灰像素水墨海洋和自然岛礁明显割裂。

## 修改

- 使用内置 ImageGen 生成独立白色像素水墨海雾组件，不烘焙海面、棋盘、舰船、岛礁、文字或 UI。
- 对首次生成结果执行透明背景修正；最终素材保留真实 Alpha，并缩放为运行时 `512×352` 透明 PNG。
- 移除逐格黑色矩形及高倍率下会露出扇贝边的规则圆雾。
- 以跨越约 4—6 格、带稳定位置和尺寸扰动的生成式干笔雾纹交叠成连续雾区，避免每格重复贴图和方形边界。
- 不修改规则层可见格、隐藏敌舰、视野滞留及刷新逻辑。

## 验收

- 不可见区域不再出现黑色方块或整齐矩形边界。
- 白雾与海洋背景自然融合，网格方向仍可辨认。
- 移动舰船刷新视野时，雾区边界随规则正确更新。
- 编译、海战冒烟测试、Alpha 检查和 OpenGL 实机截图通过。

## 验证结果

- 最终素材 `512×352`、`32bpp ARGB`；四角 Alpha 均为 `0`，雾心 Alpha 为 `254`。
- Godot `--import` 正常生成纹理缓存，运行时素材加载断言通过。
- `dotnet build --no-restore`：通过，0 警告、0 错误。
- `tests/test_naval_scene_smoke.gd`：通过，既有可见格与隐藏敌舰规则回归正常。
- Godot 4.7.1 OpenGL `1344×896`：`3×` 局部和全图概览截图均无黑色方块或规则圆边；白雾、海面及网格融合正常。
