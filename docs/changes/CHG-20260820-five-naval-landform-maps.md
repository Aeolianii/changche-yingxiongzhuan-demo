# CHG-20260820：五张固定海战地貌地图

- Status: done
- Date: 2026-08-20

## 目标

停止使用森林岛、岩山岛、港口小镇、河口岛四套旧模板。随机海战改为从峡湾、群岛、孤岛、半岛、泻湖五张固定 `24×18` 地貌地图中选择，每张地图使用一枚独立生成的大型透明水墨像素印章，不再统一套用“主岛 + 伴生小障碍”的构图。

## 地貌与战术构图

| 地图 | 主印章 | 占地与原点 | 战术重点 |
|---|---|---|---|
| 峡湾 | `fjord_v2` | `8×14 @ (8,2)` | 两侧高岩外移，中央每行至少保留四格连续深水，上下外海保留绕行口 |
| 群岛 | `archipelago_v2` | `8×12 @ (8,3)` | 五组分离陆块以整行深水隔开，形成多条穿插航线，不设单一中央主岛 |
| 孤岛 | `solitary_island_v1` | `8×8 @ (8,5)` | 单一大岛作为中央障碍，四周均可绕行 |
| 半岛 | `peninsula_arc_v2` | `8×13 @ (8,0)` | 顶部横向陆带、右侧崖壁与底部回钩组成完整厚实弧障碍，内湾和下方外海仍可航行 |
| 泻湖 | `lagoon_v2` | `8×12 @ (8,3)` | 上下两段岛弧完全断开，中间保留六行连续深水通行带 |

## 规则

- 种子只负责从五张模板中选择一张；同一模板的印章、逐格地形和出口完全固定。
- 每张模板只有一枚大型主地貌印章，水域由透明图像区域和底层 `DeepWater` 同时表达。
- 图片 Alpha 只负责表现；移动、碰撞与连通性仍读取手写地形掩码。
- 峡湾验证纵向深水贯通且最窄处至少四格，群岛验证至少五个陆地组件和四行整行深水，孤岛验证上下外海，半岛验证顶部实心弧带、内湾和下方绕行，泻湖验证至少六行连续中央通行带。
- 非标准尺寸无法容纳模板或 BFS 连通性失败时继续回退开阔海域。

## 美术约束

- 五张 PNG 使用低饱和灰青、旧赭、灰橄榄、宣纸米色的水墨像素语言，并以俯视偏正面的战术视角表现。
- 海水、峡湾水道、群岛间隔、半岛内湾和泻湖内湖必须是真实 Alpha 透明，由运行时动态海面透出。
- 素材不得包含格线、舰船、人物、文字、UI、水印、棋盘格或矩形海水底板。
