# CHG-20260820：固定海战地图战术主题与岛水分层

- Status: done
- Date: 2026-08-20

## 目标

四张固定海战地图不能只是替换中央岛屿。每张地图必须形成可读的路线取舍，同时增强岛屿与动态海面的层级，使默认倍率和全图倍率下都能迅速判断陆地边界、危险浅水与可航入口。

## 四张地图的战术主题

| 地图 | 战术主题 | 固定构图 |
|---|---|---|
| 森林岛 | 双岛夹道 | 森林岛偏左上、草洲偏右下，形成斜向中路；同时保留上路绕林与下路远航 |
| 岩山岛 | 险礁绕行 | 主山偏向一侧，扩大上方浅滩礁区；上方路线更短但进入危险水域，下方路线更远且保持深水 |
| 港口小镇 | 可驶入港池 | 港镇不只作为阻挡物；南侧进港水道连续连接外海，舰船可驶入并停在港池深水格，礁群避开港口入口 |
| 河口岛 | 险礁窄口 | `8×10` 河口岛下移，伴生险礁仍位于岛屿上方；险礁与岛岸之间完整保留两行深水移动区，不再封死上路 |

## 逻辑规则

- 所有构图仍固定并由模板选择器抽取，不恢复逐局随机摆放。
- 扩大礁区使用独立的 `7×5` 浅滩/礁石掩码；它对深水限定舰不可通行，对高通过性舰可通行并承担短路风险。
- 河口岛逻辑占地改为 `8×10`，河流仍从林地源头连续贯通至南侧河口；险礁位于 `y=0..2`、主印章从 `y=5` 开始，中间 `y=3..4` 两行必须保持完整深水。
- 港镇中央水道和港池使用 `DeepWater`，从岛外至少有一条连续深水路径抵达内部停泊格；建筑、港岸仍保持陆地阻挡。
- 主印章与伴生印章不得矩形重叠，但允许贴近或相邻，以支持山岩—险礁和河口—窄口等有意构图。

## 岛屿与海面层级

- 所有多格印章在正式纹理下方统一增加三层极淡过渡：外层深水阴影、中层浅水色、内层白色浪花。
- 三层使用同一透明纹理轮廓的轻微扩张绘制，不加生硬黑边、不生成矩形底板，也不改变地形判定。
- 过渡必须保持低对比度，不能遮住格线、舰船、范围提示或港池入口。

## 验收

- 四张全图预览能够在不看名称的情况下区分战术主题。
- 森林岛主/伴生印章横向错位；岩山主障碍偏置且使用扩大危险礁区；港池由外海深水连入；河口岛为 `8×10` 且上方险礁与岛岸之间两行完整可航。
- 四张地图保持连通，布阵区和出口安全；同一模板跨难度与种子保持固定。
- Vulkan 预览确认三层海岸过渡存在且不形成明显重影或矩形边缘。
