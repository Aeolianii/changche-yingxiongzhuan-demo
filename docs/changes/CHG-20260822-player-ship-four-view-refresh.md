# CHG-20260822：海战我方舰船四方向素材更新

- Status: done
- Type: content + naval config
- Date: 2026-08-22

## 目标

使用用户提供的两张互补四视图替换战斗中的四类我方舰船，并把四类船的逻辑占格按尺寸统一为 `1 / 2 / 2 / 3`。

## 范围

- 生成并接入 `player_{transport|frigate|merchant|flagship}_{e|s|w|n}.png` 共 16 张方向贴图。
- 第一张底行提供东/南，第二张底行逆序提供西/北；禁用两张图第一行、第三行的俯视素材。
- 四组从小到大映射为运输船、护卫舰、商船、旗舰；两种中型船共享南北端视，但东西侧视保持各自外观。
- 商船从复用运输船素材改为独立四方向素材，占格长度从 1 调整为 2；运输船/护卫舰/旗舰保持 1/2/3。

## 非目标

- 不修改敌舰方向素材、海怪、鱼群、要塞、炮台或海上大地图船只。
- 不修改舰船生命、护甲、速度、装备槽、攻击、AI 或胜负规则。
- 不使用生成式重绘，不改变源图像素风格、配色或细节。

## 验收检查

- [x] 四类我方舰船共 16 张方向贴图透明、完整且不含俯视甲板图。
- [x] 东西为互补侧视，南北为互补端视，商船使用独立资源。
- [x] 运输船、护卫舰、商船、旗舰占格分别为 1、2、2、3。
- [x] Godot 导入、C# 构建、方向素材专项测试和海战 smoke 通过。
- [x] 窗口总览确认四组尺寸层级和四方向映射正确。

- 确定性裁切工具从两张 2048×2048 源图最低透视行输出 16 张 PNG；每张只保留最大连通舰体并增加 16 像素透明安全边距，未重绘或缩放。
- Godot 4.7.1 .NET 重新导入全部 16 张贴图：通过；运输船/护卫舰/旗舰沿用现有导入配置，新增商船四方向导入资源可加载。
- Godot headless/windowed `tests/test_player_ship_directional_assets.gd`：通过；检查 16 张资源、Alpha、透明边距、方向长宽比与 `1/2/2/3` 配置，并生成 `.godot/player_ship_directional_assets_preview.png`。
- `dotnet build ChangcheHeroes.csproj --no-restore --nologo`：通过，`0` 警告、`0` 错误。
- Godot headless `tests/test_naval_scene_smoke.gd`：通过；布阵舰队、占格、战斗场景和运行时 C# 表现层无回归。
- 实际总览确认：四组从小到大清楚；东西为互补侧视；南北为端视；两艘中型船共享端视且侧视外观不同；第一、第三行俯视甲板均未接入。

## 最终核对

- Files changed: 我方舰船 16 张运行时 PNG 及导入文件、`NavalShipView.cs`、舰船配置、专项测试、规范和本变更记录。
- Limitations/follow-ups: 原素材只提供一套中型南北端视，按用户要求的两艘中型船同为 2 格处理，护卫舰与商船共享该端视；东西侧视仍各自独立。
