# CHG-20260922：补齐敌方商船四方向素材

- Status: done
- Type: content
- Date: 2026-09-22

## 目标与范围

- 修复敌方商船缺少贴图而显示灰色程序绘制俯视船的问题。
- 从 `素材参考/游戏美术更新/透明底船多视图/敌方船1.png` 与 `敌方船1_2.png` 第三行提取尚未接入的蓝色船体、白帆三桅商船，新增 `enemy_merchant_{e|s|w|n}.png`。
- 只裁切侧视和端视，保留源像素、透明背景及 16 像素安全边距；不使用中间甲板俯视列。
- 更新现有敌舰方向素材检查，使其覆盖商船。

## 非目标

- 不修改其他船型、美术源文件、两格商船占地、战斗规则或船只数值。
- 不生成新美术，不复用其他已接入船型的贴图。

## 验收与文档影响

- 四方向资源可被 Godot 加载，透明边距、有效像素及方向比例检查通过。
- 对比现有敌我舰船，确认白帆三桅商船外观独立；检查四方向实际渲染和两格显示。
- 更新 `docs/design/art-direction.md`，记录素材来源及方向映射。
- 预计修改：四张 PNG 及其导入文件、提取脚本、现有方向素材测试、美术规范、本记录。

## 验证证据

- 从两张 2048×2048 源图第三行裁切出商船四方向，保留原像素和透明安全边距；四张图经目视检查，东西向船头与标记一致，白帆三桅及船体均完整。
- `Godot --headless --editor --import` 通过，四张 PNG 均生成可加载的导入资源。
- 窗口运行 `tests/test_enemy_ship_directional_assets.gd`：`PASS: enemy ship directional assets`；预览确认敌方四种船型共 16 张资源按方向显示，商船外观与其他船型不同。
- PNG 像素哈希检查确认四张商船贴图与现有船只 PNG 均不重复；`git diff --check` 通过。
- 海战通用 `tests/test_naval_scene_smoke.gd` 在第 427 行因结算面板层级断言失败；失败发生于结算阶段，与本次贴图加载和方向预览无关。本次未调整结算 UI。
