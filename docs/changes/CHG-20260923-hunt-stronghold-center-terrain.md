# CHG-20260923：倭寇营地中央连续地形

- Status: done
- Type: content
- Date: 2026-09-23

## 目标与范围

- 将讨伐章终战中央 `9×9` 营地的逐格草地、树林和小镇图标替换为一张透明的连续海岛营寨地形印章，风格贴合现有灰青水墨海战背景。
- 在 `hunt_stronghold` 地图中接入新印章，保留左侧已有岸带。
- 修正终战城寨表现：现有规则数据已经是 `Width=2, Length=4`，但横向贴图被通用单列舰船缩放逻辑限制。使用匹配竖向 `2×4` 外形的城寨素材，并让显示位置及选中框对齐全部八格。
- 固定终战四座炮台的位置：两座在城寨上方、两座在下方，左右成对；护卫舰仍需合法放置。

## 非目标

- 不修改地形类型、城寨既有 `2×4` 规则占地、通行、碰撞、战斗数值或其他地图。

## 验收与文档影响

- 终战中央地形无逐格图标拼贴，岛屿轮廓与海面自然衔接；外缘海面保持透明。
- 新纹理可由 Godot 导入和加载；现有终战集成检查通过。
- 城寨素材覆盖并对齐竖向 `2×4` 占格；四炮台在其上、下各占同一横排两格，且与城寨和护卫舰不重叠。
- 更新 `docs/design/art-direction.md`，记录正式美术方案。
- 预计修改：中央印章 PNG、城寨 PNG、`MapScheme.cs`、终战专属敌方布阵与城寨绘制、终战集成检查、本记录和美术规范。

## 验证证据

- 使用内置 imagegen，参考原终战截图、既有港镇地形印章与横向城寨图，生成中央营地透明印章和竖向城寨 PNG；导入后在 Godot 实际场景截图中检查海岸透明衔接、城寨尺寸、炮台布局。
- 原 `ships.json` 已定义城寨 `Width=2, Length=4`，本次保持八格规则面积，仅修正城寨显示素材、宽度缩放与中心定位。
- 终战固定阵位：城寨 `(21,7)` 朝北，占 `x21–22/y7–10`；炮台 `(21,6)`、`(22,6)`、`(21,11)`、`(22,11)`；护卫舰分列外侧水域。
- `dotnet build ChangcheHeroes.csproj --no-restore -v:q` 通过（0 警告、0 错误）；Godot 4.7.1 .NET 资源导入通过；`tests/test_naval_hunt_request.gd` 的 headless 与窗口运行均通过。
