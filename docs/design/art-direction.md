# 美术方向

## 角色基准

- 人物采用用户提供的 LPC 独立帧，标准画布为 64×64。
- 原始比例导入，最近邻过滤，不通过缩放掩盖场景比例错误。

## 皇宫背景

- 俯视偏正面的像素 RPG 视角，与四方向 LPC 人物兼容。
- 中式宫殿使用朱红、黛青、暗金和灰石，温润但具有威严。
- 地面纹理清晰但不过密；一名角色的高度约等于庭院石砖宽度的 1 至 1.5 倍。
- 背景不得包含人物、文字、UI、水印、悬崖或楼梯高台。
- 正殿使用剖顶/去屋顶表现，让室内和殿外庭院同时可见；中央门洞必须连续、宽敞、没有透视高度歧义。
- 像素边缘清晰，避免写实光影、模糊笔刷和等距 3D 视角。

## 生成图用途

生成背景是可替换的原型资产。先验证角色比例与可走空间，再进入场景实现。

## 章节过场

- 第一章至第二章使用一张 16:9 古风像素水墨行程图作为视觉主体：旧宣纸底色、黛青群山、蜿蜒水路、极小舟队和由北向南的暗金路线点缀。
- 图面不得生成可辨识文字、现代地图符号、写实人物、UI 边框或水印；章节名与旁白统一由 Godot 文本控件绘制。
- 过场保持清晰的低分辨率像素边缘，同时保留干湿墨层次；禁止照片写实、柔焦和现代扁平插画。
- 四周使用自然墨晕和暗角收拢视线，行程图缓慢平移；题签使用旧纸白和低饱和金色，不使用高亮霓虹色。
- 章节题签、行程旁白及第二章题签均位于安全区内，不能与地图主体的高对比地标争抢可读性。

## 场景二对话 UI

- 第一章和第二章统一使用生成式横向像素水墨笔触作为对话底板：墨色主体略微透明，四周为透明墨锋，正文直接叠加在中部平静区域，不再使用米黄色纸张或矩形卡片作为视觉主体。
- 底板尺寸以完整承托正文和剧情选项为准，允许墨锋横向越出屏幕；正文及选项应位于墨迹中段，不得压在透明上缘或落到底板之外。
- 第一章正文采用较窄行宽并位于底板右上方安全区；第二章有选项时，正文与选项作为整体垂直排布，最下方选项仍需留在墨迹内部。
- 两幕对话框使用同一 1344×300 基准尺寸、24px 正文字号和相近单行字数；第二章选项使用 20px，仅在内部垂直布局上为选项预留空间。
- 对话人物紧邻底板两侧：水师主帅固定在左，所有 NPC 固定在右；说话者姓名铺在人物下方的独立短水墨笔触上。无人物旁白只显示正文底板。
- 底板和姓名笔触不烘焙文字、人物、按钮或场景；中文、选项、继续按钮和立绘由引擎绘制。底板允许整体拉伸，但不得破坏墨锋边缘或正文安全区。
- 对话 UI 不显示自动播放、长按跳过和其他参考图中的附加操作，只保留项目现有的点击/空格继续与剧情选项。

## 探索 HUD

- 探索 HUD 参考东方武侠游戏常见的角落式布局：左上主角徽章、左侧任务卷轴、右上菱形功能入口；只模仿信息层级和视觉语言，不复用参考图的游戏背景、人物或特效。
- UI 使用黛青黑、旧纸米色和低饱和铜金作为主色，细描边、切角和轻微阴影形成古朴金属与纸张叠层；保持半透明，让世界画面仍然可读。
- 左上主角状态区只裁切显示 `assets/characters/protagonist/picture.png` 头像，并以“水师元帅”名牌标识；状态框按 495×192 展示，头像嵌在左侧菱形框中央，“水师元帅”和“伏波将军 · 南疆水师”作为两级文字共同落在右侧宣纸框内；不显示右下角“帅”字，也不添加生命、气力、等级等未定状态。
- 左侧任务栏使用紧凑尺寸固定区分“主线”和“支线”，尽量减少对世界画面的遮挡；任务框使用一张同时包含深灰黛青水墨底色、顶部题签和墨锋外沿的完整生成式透明 PNG，不再组合程序灰色矩形。每项任务只展示主线/支线分类、任务名称和简短描述，不显示人物徽章或“帅”“商”等徽章字；任务项自身保持透明，不画完整矩形轮廓，仅以底部分隔线、分类色条和文字层级区分信息。顶部“任务”标题垂直居中于水墨题签。它是效果展示，不表达已完成的正式任务数据系统。
- 右上功能区从左到右按“任务、人物、物品栏、船只、菜单”排列，使新增任务入口位于原四个按钮左侧、菜单固定在最右侧；每个菱形按钮同时具有水墨功能图标和常显名称，不能依赖悬停提示才能识别。
- 右上四个功能符号在菱形内统一垂直居中；系统菜单六个徽章字在左侧菱形座内统一水平居中，位置调整不得改变对应点击区域。
- 探索界面五个功能入口和系统菜单六个条目不使用单字缩写作为徽章内容，统一使用无文字的水墨功能图标：以黑白墨线、宣纸灰白和少量黛青层次塑造简洁轮廓，暗金仅作极少量点缀；图标自身不包含菱形底框，由现有生成式按钮组件承载。
- “任务、人物、物品栏、船只”入口当前只反馈功能即将开放；最右侧“菜单”入口展开中央系统面板。
- 探索主界面的主角状态框、任务栏边框和功能按钮底框使用专门生成并去除色键背景的水墨风透明 PNG 组件：以墨色干湿笔触、宣纸留白和黛青墨韵为主体，只用少量暗金细线收边；主角状态框由左侧菱形头像座连接右侧宣纸名牌，任务栏只保留顶部题签和轻量墨线外框且中部完全透空，功能按钮使用统一的菱形墨框和黛青内芯。
- 探索 HUD 生成图不得烘焙人物、中文、功能符号或游戏背景，头像、文字、占位徽记和点击区域全部由 Godot 控件覆盖；组件允许按现有控件尺寸整体拉伸，但不得裁掉主要边角装饰。
- 系统菜单沿用黛青黑、旧纸米色和铜金描边，中央纵向排列“继续游戏、保存进度、读取进度、游戏设置、返回标题、退出游戏”，不显示“新手教程”；每项使用左侧菱形符号和常显中文名称。
- 系统菜单打开时以实时屏幕纹理模糊并轻度压暗后方世界及探索 HUD，菜单面板自身保持清晰；右上圆形关闭按钮必须清楚可见。
- 系统菜单框、按钮底板和关闭按钮使用专门生成并去除色键背景的水墨风透明 PNG 组件，与探索 HUD 保持同一视觉语言：以墨色干湿笔触、宣纸留白和黛青墨韵为主体，只用少量暗金细线收边；菜单框保留顶部题签和四角墨锋，按钮保留左侧菱形徽章座，关闭按钮使用水墨圆章。生成图内不烘焙文字，所有中文与符号由 Godot 控件覆盖绘制。
- 生成组件允许按现有菜单尺寸整体拉伸，但不得裁掉四角装饰、标题牌或左侧徽章座；按钮文字必须落在材质较平静的中部区域，避免纹理影响可读性。
- 系统菜单六个条目使用较舒展的纵向按钮框并留出足以避免相邻菱形徽章重合的间距，水墨主框需向外扩展并在最下方菱形与底边之间保留可见留白；文字字号固定为 21，鼠标悬浮不增加底色、不改变字体颜色，只在实际按下时保留轻微反馈。
- HUD 避开底部交互和对话区域，并能随画布尺寸保持在屏幕角落。

## 游戏设置界面

- 游戏设置作为系统菜单内的二级面板，继续使用黛青墨黑、旧纸米色、低饱和铜金描边以及清晰的最近邻像素边缘；主框、顶部题签和返回纹章复用已完成的系统菜单视觉语言。
- 界面只展示“音乐音量”和“音效音量”两项。每项由中文名称、0–100 滑动条和实时百分比组成，不混入画面、语言、按键或其他未实现设置。
- 返回按钮、滑动轨道和滑块使用与系统菜单同源的生成式透明 PNG：返回按钮为无文字回转箭头圆章，轨道为可横向拉伸的深墨绿内芯与旧金细边，滑块为小型旧金菱形像素纹章；文字保持宣纸浅色高对比，交互状态不使用现代荧光色或圆角扁平风。返回按钮下方不再增加重复的“返回”提示。
- 从系统菜单进入设置时隐藏系统菜单主框但保留同一模糊压暗背景；“返回”只回到系统菜单，不直接恢复游戏画面。
