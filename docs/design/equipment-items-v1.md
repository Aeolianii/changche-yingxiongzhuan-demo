# 《厂车英雄传》装备与物品清单 V1

- Status: proposal
- Version: 0.1
- Scope: Demo 舰船装备
- Related: [《厂车英雄传》游戏策划案 V1](game-design-v1.md)

## 1. Demo 获取规则

- 第三章首次开放船坞时，以下 19 种装备每种免费赠送 1 件，直接进入船坞库存。
- Demo 不使用军功、势力关系或章节锁定装备，玩家从首次开放船坞起即可测试全部装备。
- 免费赠送只包含每种装备的首件；重复件在船坞按表中成本制作。
- 装备可在船坞免费拆卸和换装，不永久绑定、不损坏、不使用随机词条。
- 同一个装备实例同一时间只能装在一艘船上；拆下后返回船坞库存。
- “正式版预定来源”只用于以后规划，不影响 Demo 获取。
- 当前不制作补给品、任务物品和个人装备，本文件现阶段只维护舰船装备。

## 2. 装备槽位

每艘船拥有 1 个船体槽、1 个武器槽和 1 个功能槽。同一艘船不能重复装备同名装备，装备状态跟随具体舰船跨任务保存。

## 3. 获取方式汇总

| 获取方式 | Demo 规则 | 正式版预定用途 |
|---|---|---|
| 船坞首次开放 | 每种装备免费获得 1 件 | 只赠送基础装备 |
| 船坞制作 | 所有重复件配方立即开放 | 按军功、关系或任务逐步开放配方 |
| 军功解锁 | 不启用 | 解锁标准二级、高级装备配方 |
| 势力奖励 | 不启用 | 提供少量地方特色装备或配方 |
| 任务奖励 | 不直接掉落随机装备 | 用于提供指定装备，不制作随机掉落池 |

## 7. 数值与内容边界

- 普通装备的攻击力收益不超过 +3；带行动限制的重型炮架最多提供 +6。
- 单件装备的防御力收益不超过 +2，暴击率收益不超过 +6%。
- 装备不能提供额外激活、第二次攻击、冷却重置或资源替代。
- Demo 不设置装备稀有度、随机属性、强化等级、耐久度和维修费。
- 后续新增装备时必须同时补充适用舰船、明确效果、重复件成本、Demo 获取方式和正式版预定来源。
