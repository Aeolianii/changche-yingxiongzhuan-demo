## Player promise

玩家在一张连续的岭南海防军镇场景中步行探索。地图采用第一幕皇宫已经验证的一张完整背景图方法：开局位于登陆处，码头旁海岸的鱼竿从首次加载起即可随时钓鱼；守岭人只负责提示该玩法，不承担解锁。玩家完成首次钓鱼后返回同一地图，再继续前往校场和观景台。相机只做有限跟随，景物通过道路转折、院墙、林缘和高低错落形成局部变化；画面不是完整岛屿鸟瞰沙盘。

伏波古岭现在可从海上大地图同名地点直接进入。岛内码头外端提供“乘船返回海图”触发区；玩家必须进入范围并按 `E` / 空格才离岛。返回海图后船只恢复到登岛前的近岸安全水域；本阶段重新登岛会重置岛内流程。

伏波古岭已接入全局常驻 `ExplorationUI`：角色状态、任务栏、五个功能入口和系统菜单与皇宫、场景二、海图共用唯一 HUD。伏波稳定探索状态进入正式单槽存档，恢复位置、朝向、任务阶段、钓鱼/鼓令完成状态和返航海图上下文；进行中的对话、小游戏和过场不保存。

## Scene boundary and collision method

- 主地图只使用一个完整背景 `Sprite2D`。目标源图约为 1536×1024，与第一幕皇宫的生产规格一致；若生图模型只能稳定输出邻近的 3:2 横图尺寸，采用等比裁切，不拆成多图，也不通过扩图拼接增加地图面积。
- 视口沿用项目 1344×896；`Camera2D` 平滑跟随并设置内缩限制，任何位置都不能露出底图边缘。最终相机范围在底图与角色叠放审查后确定，不再预设 3200×2200 世界。
- 地图仍包含登陆处、守岭院、古渠、校场、观景台五个叙事节点，但它们属于同一幅局部大场景。道路采用折线或 S 形连接，院墙、林缘和山石负责分隔视线，避免排成一张五点清单式导览图。
- 主线道路是一条连续的浅红褐夯土带，净宽约 144–192 像素；道路及互动空地比周围红土坡和植被更亮、更平整、纹理更少。玩家在任一镜头内都能看到道路继续方向，或看到下一个明确地标。
- 不使用连续木围栏勾勒路线。道路边界由深绿草缘、低缓红土坡、树丛和少量建筑外墙自然形成；所有装饰远离道路中心与交互空地。
- 地面、海岸、道路、院墙、房屋、树木、古渠外观、校场陈设、山体和不可进入的远景全部烘焙进背景。水流高亮、交互标记和必要剧情障碍可以保留为独立 Godot 节点。
- 玩家不能走到房屋、屋顶、大型树冠和密林后方。场景使用项目负责人红线标注形成的一条闭合分段 `CollisionPolygon2D` 边界约束活动区，因此不需要拆屋顶/树冠，也不要求环境物件前后遮挡切换。
- Y 排序只用于 Player、守岭人和以后确有需要的动态角色；背景环境不参与 Y 排序。角色碰撞仍只覆盖脚底小区域。
- `Area2D` 仅承担守岭人交互范围、古渠、校场和观景台触发，不要求触发点的美术物件从背景中切出。
- 现有 64×64 角色是绝对比例基准。道路至少容纳两名角色并行，房屋和树木不能大到占据半个镜头；地图应留出大片干净可走地面。

## Linear flow

```text
FISHING_AVAILABLE：码头出生；可直接在海岸鱼竿处钓鱼，也可先找守岭人听取提示
  -> 全屏摆钩钓鱼，首次完成后返回地图并解锁校场互动
DRUM_AVAILABLE：步行到校场入口并确认
  -> 全屏听令回鼓，完成后返回地图
VIEWPOINT_OPEN：观景台道路开放
  -> 走入观景台终点，保存人物坐标并播放 4 秒完成 CG
COMPLETE：返回原坐标，恢复自由探索并完成支线
```

海岸钓鱼入口不受守岭人对话门控，首次加载即可进入；守岭人首次对话先说明伏波古岭得名于纪念伏波将军马援，再交代伏波岛扼守海道、倭患窥伺的现状，最后提示码头旁可随时垂钓，并引向古校场听令回鼓。首次完成钓鱼后解锁校场小游戏互动，之后在校场阶段、观景台阶段和支线完成后仍可返回鱼竿重复钓鱼，重复完成不再次推进任务或发放剧情解锁。校场道路上的栏杆始终显示并保留实体碰撞，玩家可从两侧绕行；它只作为环境装饰，不承担任务门控。观景台梯子旁不再放置栅栏，也不保留透明碰撞；观景台完成条件继续由鼓令完成后的任务阶段判断。走入观景台终点后播放独立的 4 秒完成 CG，使用轻微推镜、文字分层淡入和整体淡出；播放期间锁定操作并隐藏探索 HUD，结束后把人物恢复到进入 CG 前的精确坐标，再写入支线完成状态并恢复自由探索。两项小游戏均由独立全屏 `PackedScene` 承载，运行时地图暂停并隐藏，退出或完成后恢复同一地图实例。

实现约束：宿主实际采用“禁用地图 World/HUD”而不是暂停整个 `SceneTree`，因此 `MinigameHost` 与两个小游戏根节点必须使用 `PROCESS_MODE_ALWAYS`。不得使用仅在暂停状态处理的模式，否则画面会显示但鼠标、键盘和退出操作全部失效。

## Main minigame: 海岸摆钩钓鱼

- 玩法采用“黄金矿工”式单键循环：钩线起点固定在顶部岸边木栈桥上，渔钩从岸边左右摆动；玩家按空格、回车或鼠标左键下钩；命中鱼获后自动收线，回到岸边后结算分数。
- 正式界面必须直接显示船边、绳索、渔钩、分层海水、游动鱼获、当前分数、500 分目标和 60 秒倒计时，不能只靠文字说明表达状态。
- 小鱼分低且回收快，大鱼分高且回收慢；螃蟹居中，海底岩石低分且拖慢收线。黄花鱼、大石斑、青蟹和岩石均使用独立透明水墨像素精灵，鱼获在固定安全水域中随机生成和缓慢游动，不使用复杂刚体绳索。
- 空钩或鱼获回到船边后恢复摆动；时间耗尽且未达标时显示失败与“再试一次”，不自动返回地图，也不形成软锁。
- 鱼获被成功收上岸后从本轮水池中移除，不在随机位置补刷；全部移动鱼获在金色边框内折返，背景与动态精灵均由玩法控件裁剪，不能越过边框。
- 达到目标后立即完成，根据剩余时间给出“满舱而归、渔获丰足、顺利收竿”评价，评价不影响剧情推进。
- 玩法区使用独立生成的岭南浅滩水墨像素背景，中央保留干净水域确保钩线和移动鱼获清晰；右上“暂时离开”复用海图返回按钮的水墨笔触打底，与 `Esc` 均直接退出小游戏并返回地图安全点，不再要求二次确认。

## Second minigame: 听令回鼓

- 钓鱼完成后，玩家走入校场触发区并确认，进入独立全屏校场画面，不再操控地图角色。
- 界面采用伏波完整背景压暗叠加独立生成的岭南红土校场鼓台背景；背景只包含红土空场、低矮灰砖墙、远山林木与海湾，不烘焙三面鼓或 UI。中央由 Godot 独立显示三面有大小层次的朱红中式战鼓，鼓面可以点击，下方只保留紧凑的 A/S/D 键位牌，不再用三个巨大普通按钮代替鼓。
- 示范与玩家输入时，对应鼓以暖金轮廓、鼓面冲击圈和短促跳动反馈；轮次、BPM、演示/输入阶段和当前进度必须一眼可辨。
- `A/S/D` 对应左、中、右鼓，左/下/右方向键提供兼容映射。
- 每轮示范结束后进入无限等待的准备阶段，不启动超时、不自动重播。玩家点击“准备好了·开始跟敲”或按空格/回车后先看 3、2、1 倒数；第一下正确鼓由玩家主动起拍，不检查示范结束后的等待时间，从第二拍开始才按节拍间隔计时。
- 三轮随机生成 4/5/6 拍序列，BPM 从 72/84/96 中选择且相邻轮不同；相邻鼓不重复，第三轮必须包含三鼓。
- 输入距离拍点 `±120 ms` 为正拍；正确鼓提前超过 120 ms 显示“提前·通过”且永不因抢拍失败；晚 `121–520 ms` 显示“稍晚·通过”。只有按错鼓或晚于目标拍点超过 520 ms 才重置并重播当前轮。界面常驻显示失败条件，并用“提前通过 / 正拍 / 稍晚通过”三区节拍色带和游标解释当前时机。
- 正式音频从许可清楚的独立太鼓单击录音加工：左鼓为低沉长尾鼓心，中鼓为结实中频鼓面，右鼓为短促高频鼓边；三者响度接近但音高、尾音和瞬态必须明显不同。Web 失焦时暂停，恢复后倒数三拍再继续。
- 右上“返回古岭”复用海图及钓鱼界面的水墨笔触按钮底图，与 `Esc` 均直接退出鼓令并恢复原地图，不使用二次确认框。独立运行鼓令子场景试玩时，同一入口切换到伏波古岭地图，绝不结束整个游戏进程。

## Non-goals

- 本切片已接入海图入口、全局 HUD 和正式稳定存档；经济、战斗与第三项小游戏仍不在范围内。
- 不制作分支对话、室内场景、敌人或复杂流体模拟。
- 不制作新的玩家角色、复杂流体动画或室内素材。
- 不制作四张局部背景、TileMap、地形图集、逐件建筑/树木模块或屋顶遮挡层。

- 目标场景可在 Godot 4.7 独立运行，主入口仍为标题界面。
- 主地图恰好使用一张完整背景图；运行时无背景板接缝、重复贴片或拼贴式地表。
- 初始镜头和有限相机移动不露出底图边缘，人物可用现有移动输入抵达五个叙事节点。
- 海岸钓鱼从开局起始终可用；守岭人提示可选，校场和观景台仍按首次钓鱼、首次听鼓的完成顺序门控。
- 钓鱼摆钩、发射、命中、负重收线、计分、倒计时、失败重试和目标完成均可达且永不软锁。
- 两次新运行允许听鼓答案不同；所有序列满足约束，错误重播当前轮。
- 可见碰撞与触发调试覆盖项目负责人标注的闭合活动边界、剧情节点和区域触发；线外海水、房屋、密林和山坡全部不可进入。
- 玩家无法进入屋后或树冠后方，不需要为背景房屋、树木建立前后遮挡节点。
- 运行日志无解析或阻断错误，并保留既有项目自动测试通过。
## 已确认的可活动范围（2026-08-10）

- 以项目负责人提供的红线标注为准：红线内部是唯一可活动区域，红线外全部不可进入。
- 可活动区从码头开始，沿红土主路依次包含房前支路、水渠交互点、校场军鼓空地，并延伸到观景亭入口；玩家不进入树林、房屋、水渠、山坡或海面。
- 运行时使用一条闭合的分段碰撞边界约束活动区，不再为红线外每片树林或地貌分别制作大量碰撞节点。
- 主角出生在码头。守岭人位于房前叉点；钓鱼玩法入口位于码头右侧相邻海岸的鱼竿与鱼桶处，素材底部使用半径 `36` 的可调圆形实体碰撞，外圈使用半径 `110` 的圆形交互范围；码头本体只保留返回海图。军鼓玩法入口位于鼓前叉点。背景中的古渠仅保留为岭南水利景观，不再承载玩法。
- 到达玩法叉点只显示进入提示，玩家按交互键后才打开独立小游戏；玩家可以离开触发区并选择暂不进入。

## 点击移动补充（2026-08-11）

- 伏波古岭自由探索支持左键点击地面移动；角色沿直线走向点击位置，到达目标附近后停止。
- 方向键输入立即取消点击目标。现有碰撞继续阻止穿越海岸、树林、房屋与其他边界；持续受阻时自动取消目标，不提供绕障寻路。
- 菜单、对话、小游戏、场景切换和完成覆盖层期间禁用点击移动，并清除未完成目标。
