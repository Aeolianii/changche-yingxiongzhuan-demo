## Player promise

玩家在一张中型连续岭南山岛中步行探索。开局只看见码头附近；找到守岭人后沿山道前往古渠，到达指定地点并确认后切入独立全屏小游戏，完成后返回同一地图，再继续前往校场和观景台。地图通过跟随相机形成移步换景，不以完整岛屿鸟瞰图一次展示所有地点。

## Scene boundary and layering

- 世界有效范围约为 3200×2200，视口沿用项目 1344×896；`Camera2D` 平滑跟随并限制在世界边界。
- 地图包含码头、守岭院、古渠、校场、观景台五区，推荐锚点依次为 `(420,1850)`、`(1150,1650)`、`(2600,1180)`、`(1850,620)`、`(2550,320)`。
- 地面、海岸、道路和不可进入的远景装饰由四张连续局部底图承担；相邻板块保留 12–15% 低细节重叠，不生成完整岛屿单图。
- 人物、建筑、树木按脚底 Y 排序。建筑/树木碰撞只覆盖墙基或树干；屋顶和树冠是视觉遮挡，因此人物走到后方会隐藏、走到前方会显示在物体前。
- 只有贴近道路且需要遮挡的房屋/树冠、NPC、古渠标识、号旗、军鼓和剧情障碍拆成独立节点，关键独立视觉对象控制在 10–15 个。
- 密林、山体、海岸和远景建筑群由 6–10 个大型 Godot 碰撞区整体封闭；不为底图中的单件装饰逐一制作碰撞，也不从像素自动推导碰撞。
- 像素密度以 32×32 地表模块和现有 64×64 角色为比例基准，全部使用最近邻过滤和整数像素缩放。

## Linear flow

```text
ARRIVAL：码头出生，寻找守岭人
  -> 简短对话，只开放古渠任务
CANAL_AVAILABLE：步行到古渠入口并确认
  -> 全屏三渠引水，完成后返回地图
DRUM_AVAILABLE：步行到校场入口并确认
  -> 全屏听令回鼓，完成后返回地图
VIEWPOINT_OPEN：观景台道路开放
  -> 走入观景台终点
COMPLETE：显示完成提示
```

与守岭人交谈前古渠入口不触发；守岭人只开放任务，不在守备院直接启动小游戏。两项小游戏均由独立全屏 `PackedScene` 承载，运行时地图暂停并隐藏，退出或完成后恢复同一地图实例。

## Main minigame: 三渠引水

- 画面上方为来水口，下方为左、中、右三块蓄水田；玩家用鼠标选择渠道并点击“放水”。
- 三轮分别分配 3、4、5 股水。后两轮随机改变目标，并可能封闭一条目标为零的支渠；所有题目来自已验证的可解配置池。
- 超过目标或流入封闭支渠只重置当前轮，保留同一目标重新开始；不设倒计时。
- 根据总操作次数给出“善治、通达、疏浚”评价，评价不影响剧情推进。

## Second minigame: 听令回鼓

- 古渠完成后，玩家走入校场触发区并确认，进入独立全屏校场画面，不再操控地图角色。
- `A/S/D` 对应左、中、右鼓，左/下/右方向键提供兼容映射。
- 三轮随机生成 4/5/6 拍序列，BPM 从 72/84/96 中选择且相邻轮不同；相邻鼓不重复，第三轮必须包含三鼓。
- 输入距离拍点 `±120 ms` 为正拍，`±121–280 ms` 仍通过，超过 `±280 ms` 或按错鼓只重置并重播当前轮。
- 正式音频使用低沉鼓心、中频鼓面和清脆鼓边三份独立 WAV；Web 失焦时暂停，恢复后倒数三拍再继续。

## Non-goals

- 本次不接入主流程、海图入口、存档、经济、战斗或第三项小游戏。
- 不制作分支对话、室内场景、敌人或复杂流体模拟。
- 不制作新的玩家角色、复杂流体动画或室内素材。

## Acceptance

- 目标场景可在 Godot 4.7 独立运行，主入口仍为标题界面。
- 初始镜头只显示局部，人物可用现有移动输入探索五区。
- NPC、古渠、校场和观景台按六阶段门控，不能跳过。
- 27 种古渠状态只有目标组合完成；错误状态报告正确前缀和泄水方向且永不软锁。
- 两次新运行允许听鼓答案不同；所有序列满足约束，错误重播当前轮。
- 可见碰撞与触发调试覆盖世界边界、建筑墙基、树干、水池、剧情障碍和区域触发。
- 人物在至少一座建筑和一棵树的前后移动时遮挡关系正确。
- 运行日志无解析或阻断错误，并保留既有项目自动测试通过。
