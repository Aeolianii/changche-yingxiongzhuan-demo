# 场景串联流程

- Status: approved
- Last updated: 2026-08-11

## 顺序

`场景一：皇宫召见 -> 主帅领旨 -> 像素水墨南下行程 -> 水师副将迎接 -> 场景二自由探索`

项目从 `res://scenes/ui/title_screen.tscn` 启动。标题界面选择“开始新游戏”后进入 `res://scenes/palace/palace_demo.tscn`；场景一进入 `complete` 状态并显示“水师主帅领旨南下”后，等待 2.5 秒自动开始章节过场；玩家也可以点击“立即启程”跳过这段等待。按钮不会跳过章节过场本身，也不出现章节选择或额外确认界面。

## 标题界面流程

- “继续游戏”仅在正式单槽存档存在时可用。点击后通过 `GameState.load_game()` 校验存档，并切换到存档记录的皇宫、水师驻地、海上大地图或伏波古岭；失败时留在标题界面并显示原因。
- “开始新游戏”清除内存中的待恢复快照并进入皇宫开场，但不删除磁盘上的既有存档。玩家之后主动保存时才覆盖旧槽。
- “游戏设置”在标题画面内打开音乐与音效音量面板，返回后恢复主菜单；“退出游戏”结束应用。
- 标题界面不自动读取存档，避免玩家无法选择新游戏；它必须清楚显示是否存在可继续进度。

章节过场按以下顺序播放：

1. 淡入古风像素水墨南下行程图，并依次显示“诏令既下，星夜南驰。”和“越千山，渡长河，抵南疆。”。
2. 行程图淡出后切入 `res://scenes/Scene2.tscn`，水师副将先行迎接并请主帅巡视中军楼船。
3. 迎接对白结束后恢复玩家控制和探索 HUD，主线任务更新为“巡视水师驻地”，第一步要求与左右两名甲板值守士兵交谈。
4. 第二幕章节迎接、士兵汇报、军官复命和县令商议等线性对白可点击按钮或按统一 `interact` 输入（空格、E、回车）逐句推进；包含明确选项的 NPC 对话仍由玩家点击选项。

## 第二章巡视与操练

第二章首段剧情以对话推进，不设置环境调查点：

1. 主帅分别与中军楼船左右两名值守士兵交谈，听取岗哨和舰船战备汇报；顺序不限，重复交谈不重复累计。
2. 两名士兵均已汇报后，主帅向位于甲板中部的中军军官复命；该对白结束即完成“巡视水师驻地”。
3. 主线更新为“筹备水师操练”，引导主帅与广州县令首次会谈。县令说明水师多年疏于操练、沿海海情与旧海图均不完备，需要主帅在检阅操练后亲自出海巡视。
4. 广州县令与中军军官是两个独立 NPC。县令负责地方军需与海情会谈，并在会谈结束后开启完整海战操演主界面；军官不直接开启操演。
5. 从甲板进入操演时先锁定输入、隐藏探索 HUD 并缓慢淡至黑屏，再切换到 `res://scenes/naval/LevelSelect.tscn`；海战主界面从黑屏淡入。进入前保存主角在县令对话开始前的精确坐标、朝向与任务阶段。

## 操练后进入岭南海域

1. 玩家点击海战主界面右上角“返回”后，海战界面淡黑并切回 Scene2；Scene2 从黑屏缓慢亮起，主角恢复到进入县令对话前的精确坐标与朝向。首次操演返回后，任务栏与任务界面更新为“探索海域，完善海图”，当前目标为“与广州县令交谈，选择是否立即出发”。
2. 再次与广州县令交谈时，县令询问“将军是否要巡视一下岭南海域？”，固定提供三个选项：“出海”沿用既有大地图入口、“操演”重复打开海战主界面、“无事”关闭对话；选择“无事”不会丢失任务进度。
3. 选择“立即出发”后显示至少一秒的像素水墨加载界面及“正在进入大地图”，随后切换至海上大地图，玩家固定出生在南海军港半圆港湾内部并立即处于可进入范围。
4. 从南海军港进入时显示至少一秒的同款加载界面及“正在进入南海军港”，随后返回场景二。
5. 返回场景二后恢复到操练完成后的任务阶段；士兵巡视、军官复命、县令首次会谈和水师操练均不重复触发，再次与县令交谈仍进入既有岭南海域出发询问。

## 场景边界

- 场景一继续使用 GDScript 状态机，不改写既有剧情步骤。
- 场景二使用 GDScript；来自第一章的首次入口增加水师副将迎接对白，随后通过士兵汇报、军官复命和县令会谈推进任务并进入既有操练逻辑。
- 两个场景共享合并项目的输入映射、窗口设置和渲染后端。
- 首版通过场景树根节点的一次性元数据区分“章节一进入场景二”“场景二进入海上大地图”和“海上大地图返回场景二”。返回入口直接恢复操练完成后的稳定任务阶段，不传递角色坐标、完整任务数据或存档。

## 海图与伏波古岭往返

1. “伏波古岭”是当前十五个海图地点中唯一接入真实岛屿场景的地点；它立即开放，不设剧情门槛。其他未接入地点继续显示原有占位提示。
2. 船只进入伏波古岭入口范围后，底部操作条显示地点名称；玩家点击“进入”或按 `E`，加载界面显示“正在登陆伏波古岭”，随后切换到 `res://scenes/fubo_guling/fubo_guling.tscn`。
3. 岛屿主角仍从码头出生。码头端点增加“乘船返回海图”触发区；进入范围只显示提示，必须按 `E` / 空格确认，不会因走过触发区自动离岛。
4. 返回海图时重新实例化海图场景，并恢复登岛前船位、朝向、探索阶段和月相。返回上下文缺失或损坏时，船只放到伏波古岭附近已验证可航的安全点 `Vector2(4200, 1140)`。
5. 岛内四个稳定自由探索阶段可写入正式存档，恢复人物位置、朝向、阶段、钓鱼/鼓令完成标记和返航上下文；对白、小游戏、加载和完成覆盖层不保存。未读取岛屿存档而重新登岛时仍从初始状态开始。连续输入在加载期间被锁定，场景切换失败则留在当前场景并恢复控制。

## 失败与恢复

若场景二无法加载，场景一保持在完成态，关闭章节过场并恢复“重试启程”按钮，同时显示作品内错误提示；不得静默黑屏或退出。

## 跨场景探索 HUD

- 探索 HUD 已迁移为全局常驻 `ExplorationUI` Autoload。皇宫、场景二、海图和伏波古岭不再各自实例化 HUD，而是按场景接管唯一实例；标题界面保持 HUD 隐藏。
- 场景切换时旧场景释放 UI 所有权并清除菜单、任务页、海图页和 toast 等瞬态状态，新场景加载后提交自己的任务上下文。任何时刻不得出现两份 HUD 或上一场景任务残留。
- 场景一和场景二共用同一套探索 HUD，不在两个场景中复制视觉实现。
- HUD 只代表自由探索状态：玩家可控制移动，且没有对白、开场旁白、操练演示、自动角色过场或场景淡出时显示。
- 场景一的 `WAIT_TALK` 与 `GO_TO_EMPEROR` 是主要显示阶段；`OPENING_REPORTS`、`ATTENDANT_WALKS_OUT`、对白状态、完成旁白和场景切换期间隐藏。
- 场景二在普通甲板移动与 NPC 接近提示阶段显示；章节入口迎接对白、普通对话框或操练覆盖层可见时隐藏，并在关闭这些覆盖层后恢复。
- 自由探索阶段可从右上菜单按钮进入共享系统菜单暂停态；暂停态保留模糊后的探索画面作为背景，停止角色移动并阻止 NPC 交互。
- 系统菜单右上关闭按钮返回原自由探索状态；“游戏设置”进入同一覆盖层内的音频设置子面板，可调节音乐与音效音量，点击返回后恢复系统菜单；“退出游戏”直接结束应用。
- “继续游戏”关闭系统菜单并恢复当前探索；“保存进度”将当前稳定探索状态写入单槽存档；“读取进度”校验单槽存档后切换或重载记录场景。保存或读取失败时留在当前场景并显示原因。“返回标题”切换到标题界面且不改写正式存档。
- 正式存档会跨进程保留；除标题界面的“继续游戏”外，玩家仍可在自由探索系统菜单中点击“读取进度”。
- 存档边界覆盖皇宫、水师驻地、海上大地图和伏波古岭的自由探索状态，不尝试恢复对白、章节过场、加载过场、操练覆盖层或小游戏的中间帧。

## 陆地探索移动

- 皇宫和水师驻地自由探索同时支持方向键与鼠标左键点击移动；点击地面后，主角沿直线朝对应世界位置移动。
- 键盘方向输入优先并立即取消点击目标。抵达目标、持续被碰撞阻挡、打开菜单/对白/操练覆盖层或开始切场时同样取消点击目标。
- 点击移动复用既有物理碰撞，不提供绕开墙体或大型障碍的路径规划；海上大地图继续使用现有船只方向键操控。
