# 场景串联流程

- Status: approved
- Last updated: 2026-07-20

## 顺序

`场景一：皇宫召见 -> 领旨南下 -> 淡出过场 -> 场景二：南疆水师`

项目从 `res://scenes/palace/palace_demo.tscn` 启动。场景一进入 `complete` 状态并显示“水师主帅领旨南下”后，等待 2.5 秒自动淡出并加载 `res://scenes/Scene2.tscn`。玩家可以点击“立即启程”跳过等待，但不出现章节选择或额外确认界面。

## 场景边界

- 场景一继续使用 GDScript 状态机，不改写既有剧情步骤。
- 场景二继续使用 C#，不改写其运行时场景构建、NPC 对话和操练逻辑。
- 两个场景共享合并项目的输入映射、窗口设置和渲染后端。
- 首版不在场景之间传递角色坐标、任务数据或存档。

## 失败与恢复

若场景二无法加载，场景一保持在完成态，恢复“重试启程”按钮并显示作品内错误提示；不得静默黑屏或退出。
