# 海怪与 Boss 战 · 设计起点

> 本文件为新开窗口的设计会话提供起点与上下文。当前会话（原窗口）在后台拉取远程参考仓库，两边独立进行。

## 任务
敲定**海怪（Sea Monster）**与**Boss 战（Boss Battle）**的设计——作为海军棋战的新遭遇类型/特殊单位，并考虑与现有规则、未来海图大地图的接轨。

## 现有游戏上下文（已实现）
- 方格制单舰海战（Godot .NET 4.7.1），类《将军的荣耀》回合战棋。
- 舰船：旗舰/护卫舰/商船/运输船，多格占位、朝向、通过性、负载/护甲、武器（箭雨/撞角/火炮/接舷/砲击）、技能（链弹/火油/水雷/损管）。
- 天气/风向/地形/视野/迷雾/回合/布阵/装备配置/自沉/逃跑/投降/维修。
- 教学关卡系统（3章8关）、随机遭遇战（随机地图+敌人，U-2）、测试关卡、舰队配置修改器。
- 设计文档：`docs/design/core-naval-combat-design.md`（2026-07-25）、`docs/design/map-design-rules.md`、`docs/design/ship-upgrade-mechanism.md`。

## 待定的关键问题（新窗口从这里开始 brainstorm）
1. **定位**：海怪/Boss 是特殊敌方单位、特殊遭遇战类型、还是剧情/大地图事件？
2. **单位形态**：多格大实体？独有属性（血/甲/负载/通过性/占格数）？独有技能（触手、喷墨、召唤、部位破坏等）？
3. **战斗流程**：普通遭遇战规则直接套用，还是独有机制（阶段、部位、弱点、回合限制）？
4. **奖励**：特殊掉落（占位）？与升级/经济（铁木麻钱）怎么接？
5. **AI**：海怪/Boss 的差异化 AI（进攻/守势/阶段切换）？
6. **与海图大地图接轨**：作为特定区域/剧情遭遇，进入方式？

## 设计方法建议
- 用 superpowers:brainstorming 从"定位"问题逐个敲定。
- 设计结果写成 `docs/design/sea-monster-boss-design.md`，供实现使用。
- 保持与现有规则低耦合：先定概念，再定数值与实现接点。
