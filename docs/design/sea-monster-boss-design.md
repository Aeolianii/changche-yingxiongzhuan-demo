- 状态：已通过对谈确认，待书面复核
- 日期：2026-08-17
- 目标版本：Godot .NET 4.7.1 Demo（海战demo03-ui优化版）
- 设计起点：`docs/design/sea-monster-boss-design-start.md`
- 参考文档：`docs/design/core-naval-combat-design.md`、`docs/design/map-design-rules.md`、`docs/design/ship-upgrade-mechanism.md`、`docs/tech/architecture.md`、`帆船时代：官方水师军港与海盗据点的配置差异.md`

## 0. 术语与数值口径

- **阶段血量池**：海怪总血量按阶段均分（本文档中 1000 HP = 两阶段各 500）。水雷对海怪按单阶段血量池计算。
- **质量**：怪物用于「撞角式近战」的撞击基础量，替代舰船的实际负载参与 `实际负载 × 撞角系数 × 修正系数20`。
- **专属装备/宝物**：击破后获得的独有装备，掉落即解锁，进入装备配置或舰队全局栏。

## 1. 定位与入口

- 新增**讨伐（Hunt）遭遇类型**：关卡选择主界面新增「讨伐」章，列出三个固定入口：**海怪01 章鱼怪 / 海怪02 鱼群 / 倭寇大本营（Boss）**，玩家主动选择挑战。
- 讨伐战走现有「布阵 → 战斗 → 结算 → 维修」闭环；掉落与钱财在主界面结算。
- 与随机遭遇战、测试关卡并列，不参与教学关卡顺序；独立注册，不写进 `LevelRegistry` 教学进度体系。

## 2. 海怪通用规则（海怪01/02 共通）

- **不可被推动**：任何撞击/强制位移/推进均无效。
- **不会逃跑**：不因接触出口边界离场。
- **不可被劝降**：不参与投降结算、不可被俘获、不可接舷（不适用接舷/俘获/损管/投降相关技能）。
- **玩家侧**：玩家舰船可正常逃跑（地图出口生效）。
- **胜负**：海怪被击沉 = 玩家胜；玩家舰队全灭或全部逃跑 = 玩家败。
- **战败后果**：只损失本场被击沉的舰船；存活舰战后正常免费维修。无劝降/交付舰惩罚。
- **AI**：海怪使用专属差异化 AI（`SeaMonsterAi` / `FishSchoolAi`），不复用基线 `NavalAi` 舰船逻辑。

## 3. 海怪01 章鱼怪

### 3.1 基础数据

| 项 | 值 |
|---|---|
| 占位 | **2×2 矩形体**（无朝向、无转轴、不可转向） |
| 通过性 | 仅深海（`Passability.DeepWaterOnly`） |
| 总血量 | **1000**（两阶段行为切换，不重置） |
| 护甲 | 2（减免 20% 可减免伤害） |
| 质量 | **10**（= 旗舰载重上限 5 × 2，用于撞角式近战） |
| 舰型大类 | 复用舰船大类（`ShipDefinition` 扩展），非独立实体系统 |

### 3.2 两阶段机制

- 总血量 1000，**阶段仅行为切换、不重置、不清状态**。
- 血 > 50%（>500）：一阶段（触手）；血 ≤ 50%（≤500）：二阶段（狂暴）。
- 阶段切换时机：任意伤害结算后按当前血量即时判定，切换后本回合行为按新阶段执行。

| 维度 | 一阶段 | 二阶段 |
|---|---|---|
| 攻击 | 触手近战（撞角式、可推动） | 一阶段近战 + 移动伤害 |
| 移动 | 每 2 回合移动 1 次，水下移动 8 格，上浮落点避开舰船格 | 水面/水下移动（见 §3.5） |
| 移动预告 | 无 | 行动前 1 回合显橙色路径（水面）或 4 格上浮点（水下） |
| 移动伤害 | 无 | 水面路径 / 上浮点伤害（见 §3.5） |

### 3.3 触手攻击（近战·撞角式）

- 攻击基础伤害 = `质量(10) × 修正系数20 × 攻击系数`，可被目标护甲减免；命中可推动目标（海怪自身不可被推动）。
- 几何：以 2×2 方块为中心，**上下左右四方向各 2 根触手（共 8 根）**，沿直线延伸，射程内选取目标。
- 攻击选取（AI 决策）：
  - 射程内可攻击目标 **≥2** 个：多根 **1×3** 触手分别覆盖（系数 **0.3**）——面杀伤。
  - 射程内仅 **1** 个目标，或存在**高价值目标**（旗舰/指挥舰/护卫）：单根 **1×5** 触手（系数 **0.5**）——纵深点杀。
- 触手攻击受护甲减免，每格命中独立结算。

### 3.4 状态与交互

| 交互 | 规则 |
|---|---|
| 锁链弹减速 | **免疫** |
| 火油 | 生效，但持续回合 **−1**（3 → 2 回合） |
| 水雷 | 见 §3.6 通用水雷交互 |
| 损管/接舷/俘获/投降 | 不适用（海怪通用） |
| 烧伤/台风/礁石 | 烧伤正常结算；台风/礁石不适用（仅深海、不占礁石） |

### 3.5 移动（含二阶段移动伤害）

- **一阶段**：每 2 回合移动 1 次，水下移动，最多 **8 格/次**；上浮落点（停留格）避开舰船占格。
- **二阶段**（移动后仍可正常攻击）：
  - **水面移动**：每回合 1 次，距离 **6 格**；行动前 1 回合确定路径并显示为**橙色**；路径覆盖到的敌舰每格承受系数 **0.9** 伤害。
  - **水下移动**：每回合 1 次，动完**之后 2 回合不再移动**；距离不限制；行动前 1 回合确定 **4 个上浮格**，上浮格上单位承受系数 **1.2** 伤害并被**强制向四面推开**。
  - 两种移动的选择比例约 **水面:水下 ≈ 3:1**（AI 掷骰决定）。
- 移动路径**不规避水雷**，正常触发水雷并承受雷伤。

### 3.6 水雷交互（通用规则）

- 每个海怪/怪物单位在数据中声明 `MineDamageRule`：
  - `PercentOfMaxHp: <值>`：每颗雷造成「最大生命 × 值%」的无视护甲伤害。
  - `Immune`：免疫水雷（穿过不触发）。
- 普通舰船沿用现有「最大生命 30%」规则，不受影响。
- 海怪01：`PercentOfMaxHp: 12.5` → 每颗雷 = 1000 × 12.5% = **125**（= 单阶段血量池 500 的 25%）。
- 未来新增海怪只需在数据里声明自己的雷伤规则，规则层按字段执行，无需改代码。

## 4. 海怪02 鱼群

### 4.1 基础数据

| 项 | 值 |
|---|---|
| 组成 | 3 个独立单位，各占 **1×2 格**（长条、有朝向，横向/纵向） |
| 各自血量 | **300**（可被逐个击沉） |
| 护甲 / 质量 | 护甲 1 / 质量 5 |
| 通过性 | 全海域（浅滩/礁石可过，吃礁石 15% 最大生命伤害） |
| 速度 | **V5 = 12 格/回合**（新增最高速度档） |
| 水雷 | `MineDamageRule: Immune`（穿过不触发） |

### 4.2 移动

- 普通移动 V5（12 格/回合）。
- **飞越**：移动/冲撞时可**飞越 2 格宽的小岛/礁石/陆地**（不落地、不结算地形伤害，落在第 3 格水域）。
- 链弹减速**生效**；火油**生效**（不缩短）。

### 4.3 主攻·线性冲撞

- 选定方向直冲最多 **8 格**，路径上**首个**敌舰承受冲撞伤害 = `质量(5) × 20 × 攻击系数`（可减免）+ 被推动 1 格；撞到陆地/山脉停下。
- 冲撞可配合飞越机制跨障碍。

### 4.4 数量模式与集火链

| 数量 | 模式 | 行为 |
|---|---|---|
| **3 条** | 猎杀阵型 | 每 **3 回合**进入「狩猎回合」：三单位同一回合**依次冲撞同一锁定目标**形成三连击——第 1 击 AI 锁当前可达的**低价值目标**（商船/运输船），第 2、3 击各以 **50%** 概率改锁**高价值目标**（旗舰/指挥舰/护卫）；目标被击沉或脱离射程则重新选目标。平时冲撞系数 **0.8**，AI 倾向包夹走位 |
| **2 条** | 追击阵型 | 集火变「双连」（第 1 击低价值、第 2 击 50% 高价值），单条冲撞系数 **0.9** |
| **1 条** | 困兽模式 | 攻击切换为「狂暴冲撞」：系数 **1.2**，且冲撞后**可再移动**（以冲撞代攻击，突破「攻击后禁移」）；AI 专注高价值目标，威胁度最高 |

- 击沉一条即切换模式（3→2→1），无需额外触发条件。

## 5. Boss战 · 倭寇大本营

### 5.1 定位与地图

- 海盗据点风格（参考《帆船时代》海盗据点逻辑：隐蔽、浅滩礁石、窄航道、预警、机动迎战，不修永备工事）。
- **地图与城寨一体设计**：规格参考 24×16 ~ 28×18。
- 布局：**玩家布阵区[左·深水] → 中央交战带（浅滩/礁石/窄航道咽喉） → 倭寇内港[右]**；城寨与炮台沿岸/内港布防，敌舰队停泊护航。
- 地图满足现有可玩性原则：布阵区恒深水、区中心连通、海域占比 ≥20%、出口列存在（供玩家逃跑）。

### 5.2 主城寨

| 项 | 值 |
|---|---|
| 占位 | **2×4 矩形体（8 格）**，自沉固定，不可移动 |
| 身份 | **敌方旗舰/指挥舰**（讨伐战中指挥舰与城寨合一） |
| 血量 / 护甲 | HP **2000** / 护甲 **3** |
| 火力 | **火炮×2**（Lv2，每门 400）+ **砲击×2**（Lv2，单件 280） |
| 射界 | 普通舰船射界；自沉固定火力点每回合一次普通攻击 |
| 目标 | **击沉主城寨即玩家胜利** |

### 5.3 岸基炮台 ×4

| 项 | 值 |
|---|---|
| 占位 | 单格自沉小舰，沿岸/卡口布防 |
| 血量 / 护甲 | HP **200** / 护甲 **2** |
| 火力 | 火炮×1（Lv1，每门 300） |
| 作用 | 封锁航道，削弱玩家推进；非胜利必要条件，可留存 |

### 5.4 敌舰队

- 难度 3 舰队（旗舰+护卫精锐、**进攻型**策略），主动出击护航城寨。
- 复用现有敌舰队配置/随机生成体系（`EnemyFleetConfig` / `RandomEnemyFleetGenerator`），按难度 3 生成。

### 5.5 胜负

- **胜利**：击沉主城寨即胜；炮台/舰队留存不影响胜利，仅影响战果展示与奖励展示。
- **失败**：玩家舰队全灭或全部逃跑。
- 讨伐战不启用双方劝降（海盗死战；我方胜利条件独立于全歼），战斗结束只由击沉/全灭/逃跑判定。

## 8. 平衡基准（初版，可调）

- 玩家舰队配置上限 **12 艘**。讨伐基准满编示例：2 旗舰 + 3 护卫 + 3 运输 + 4 商船 → 总血量 = 2×500 + 3×400 + 3×250 + 4×150 = **3550**。
- 海怪01：1000 血 / 单次触手 60–240；玩家 3550 总血对砍，海怪威胁集中在点杀高价值舰。
- 海怪02：3×300 = 900 血 / 冲撞 80–120；机动性强、集火危险，靠飞越与免疫水雷制造压力。
- 大本营：城寨 2000 + 炮台 4×200 + 难度 3 舰队；胜利只需击沉城寨 2000，攻城节奏。
- 以上数值均为初版基准，实现后按试玩反馈调整。

## 9. 架构与实现接点

### 9.1 占位几何扩展（核心）

- `GeometryRules` / `ShipState` / `BattleMap` 支持两种占位形态：
  - **线性 1×N**：现有模型（有朝向、转轴、撞击方向判定）。
  - **矩形 W×H 体**：海怪01（2×2）、主城寨（2×4）。无转轴、不可转向（或仅允许 H/V 朝向定义）、攻击从四边锚定。
- 影响范围：占格计算、转向合法性、攻击锚点/射界、撞击/推动判定（矩形体自身不可被推动）、占格渲染。
- 复用现有「攻击覆盖船体格即命中」「逐格伤害」结算，不改伤害模型。

### 9.2 配置与数据

- **V5 速度档**：`BattleConfig` 速度表 V0..V5 扩展（V5=12）。
- **新单位数据**：城寨（2×4 自沉）/ 炮台（1×1 自沉）/ 海怪01（2×2）/ 鱼群（1×2）进入舰船体系（复用 `ShipDefinition` 大类），海怪专属字段扩展：
  - `Shape`（线性/矩形 W×H）、`PhaseConfig`、`Mass`、`MineDamageRule`、状态豁免标志。
  - 倾向并入 `ships.json`（或独立 `monsters.json`，由 `NavalConfigLoader` 统一校验），符合「用船只大类」定位。
- **讨伐注册**：新增讨伐入口注册（三个固定挑战），走固定遭遇路径（复用 `RandomEncounterGenerator.CreateFromDefinition` 的固定遭遇分支），追加怪物/城寨单位装配。

### 9.3 规则类

- `SeaMonsterRules`（海怪01）：阶段判定/触手攻击/两阶段移动与移动伤害/上浮预告/状态豁免/水雷减伤。
- `FishSchoolRules`（海怪02）：数量模式切换/线性冲撞/飞越/集火链（三连/双连/狂暴）。
- 城寨/炮台：复用现有**自沉** + 普通攻击机制（`SelfSinkCommand` 布阵强制自沉），仅需新增舰型与布阵装配，不新增规则类。
- 移动伤害预告（橙色路径/上浮点）作为新命令与事件类型，表现层渲染预告后下回合结算。

### 9.4 AI

- `SeaMonsterAi`：触手目标选取（多目标 1×3 / 单或高价值 1×5）、移动决策、二阶段水面/水下 3:1 选择、上浮避船。
- `FishSchoolAi`：目标价值选择（低价值首击/50% 高价值改锁）、三连集火编排、数量模式切换、困兽狂暴。
- 敌舰队/炮台：复用 `NavalAi`。

### 9.5 表现层与入口

- **讨伐章**：`LevelSelectController` 新增「讨伐」章 + 三个入口卡，复用关卡选择 UI 模式。
- **掉落**：装备配置 UI 支持专属 Lv4 武器（撞角/砲击位）；新增舰队级宝物槽（军旗），主界面「舰队/宝库」栏展示与挂载。
- **表现铁律**：UI 只做「输入 → BattleCommand」「BattleEvent → 可视反馈」，怪物合法性一律规则层查询。

## 10. 测试与验收

- **规则层单测**（`tests/NavalCombat.Tests/`）：
  - 矩形 W×H 占格、无转轴、攻击锚点、不可推动。
  - 海怪01：阶段切换、触手两种选取与伤害、两阶段移动与移动伤害、上浮预告、锁链弹免疫、火油减回合、水雷 12.5%（125）。
  - 海怪02：三模式切换、冲撞、飞越 2 格、免疫水雷、集火链首击/改锁逻辑。
  - 城寨/炮台：自沉装配、火力、击沉城寨即胜、敌方旗舰=城寨。
  - 全局血量重调后，更新受影响断言。
- **headless 冒烟**：讨伐章入口 → 布阵（城寨/炮台自沉固定）→ 战斗 → 击沉城寨胜利 → 结算掉落/钱财。
- **门禁**：`dotnet build` 0 警告 0 错误；规则测试全绿；冒烟全绿。

## 11. 非目标与后续

- 本期不做海怪皮肤/动画精修，先保证规则正确。
- 海怪 01/02 专属地图暂不独立制作，讨伐战复用现有地图生成/方案体系（或为海怪专设深水图/礁石图，见实施计划）。
- 更多海怪种类与雷伤规则后续按 `MineDamageRule` 数据扩展即可。
- 海图大地图（设计起点提及的未来接轨）暂不在本期实现范围，讨伐章作为大地图事件的前置载体预留。
