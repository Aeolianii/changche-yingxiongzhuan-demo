# 伏波古岭接入海上大地图设计

- Status: implemented and verified
- Date: 2026-08-11
- Owner: Project owner / Codex

## Goal

把海上大地图中已经存在的“伏波古岭”地点从占位提示改成现在即可进入的真实岛屿，并形成“海图靠岸—岛内探索—码头离岛—回到原船位”的双向闭环。

## Player flow

1. 玩家驾驶船只接近东北海域的伏波古岭，进入比登岛入口更宽的军情触发范围。
2. 水师士兵禀报伏波古岭守军防范倭寇、巡查烽堠的职责；玩家选择“收到，我会前去巡视。”后接取“伏波古岭”支线。
3. 玩家进入现有近岸触发范围，地点提示显示“进入伏波古岭”；点击进入按钮或按 `E` 后播放现有加载过渡。未接取支线时尝试登岛会先补发军情对话，不会切换场景。
4. 切换至 `res://scenes/fubo_guling/fubo_guling.tscn`，主角从岛屿码头安全点出生。
5. 玩家可照常与守岭人交谈、钓鱼、听令回鼓并登上观景台。
6. 玩家走到码头外端的离岛范围时显示“按 E / 空格 乘船返回海图”；离开范围则关闭提示。
7. 确认离岛后播放加载过渡并切回海上大地图。船只恢复到登岛前的近岸安全水域，月相与大地图探索阶段不倒退。

海图主线始终为“探索海域，完善海图”，“伏波古岭”只作为支线存在。直接运行岛内场景用于调试时，系统自动补发并追踪该支线。

## Architecture

### Sea-overworld entry

`scripts/sea_overworld.gd` 继续负责动态建立 15 个地点。`_build_location()` 增加可选目标场景路径元数据；只有“伏波古岭”配置 `res://scenes/fubo_guling/fubo_guling.tscn`，其余地点继续显示现有“即将开放”提示。

进入伏波古岭前，海图把以下会话级返回上下文写入 SceneTree 根节点元数据：

- 船只当前位置；
- 船只朝向索引；
- 大地图探索阶段；
- 当前月相日数。

随后禁用船只控制、隐藏进入提示与探索 HUD，复用 `SceneLoadingTransition` 切换场景。若切换失败，必须删除入口标记、恢复控制和 HUD，并给出错误提示，不能把玩家留在锁定状态。

### Island exit

`FuboGuling` 新增独立的 `SeaReturnTrigger`，位置位于码头外端，避免与现有码头钓鱼触发区重叠。进入范围只设置 `_pending_trigger = "sea_return"` 并显示离岛提示；按交互键后才切换，不自动离岛。

岛屿场景无论从海图进入还是直接调试，都允许使用码头离岛入口。直接调试缺少返回上下文时，海图使用伏波古岭入口附近的固定安全水域作为回退船位。

### Sea-overworld return

海图 `_ready()` 消费伏波返回标记和返回上下文。若上下文完整，则恢复船位、朝向、探索阶段与月相；若上下文缺失或坐标非法，则使用伏波古岭近岸的已验证安全水域。返回后保留玩家控制，进入提示可按实际重叠状态重新显示，但不得自动再次登岛。

伏波支线的接取状态、岛内稳定进度以及当前追踪支线保存在 `GameState.world_state`，沿用存档版本 1 并兼容缺少这些字段的旧存档。玩家在任务界面点击任一支线后，左侧任务栏立即改为追踪该支线。

## UI and feedback

- 海图地点名仍为“伏波古岭”，进入按钮沿用现有大地图 UI。
- 海图不再对伏波古岭显示“该岛屿即将开放”。
- 岛内复用现有底部 `PromptPanel` 显示离岛提示，不新增常驻按钮或确认框。
- 海图进入与岛内返回均使用现有加载过渡，文案分别为“正在登陆伏波古岭”和“正在返回岭南海图”。

## Error handling

- 入口目标场景不存在或切换失败：保留海图场景，恢复船只控制/HUD/提示，并显示失败提示。
- 离岛切换失败：保留岛屿场景，恢复角色控制和离岛提示，允许玩家重试。
- 返回上下文缺失、类型错误或坐标非有限值：忽略坏数据并使用固定安全水域。
- 所有入口都受 `_transitioning` 防重入保护，连续点击或重复按键只触发一次切换。

## Tests

- 海图地点契约：15 个地点数量不变；伏波古岭目标场景正确，其余地点仍为占位。
- 海图入口测试：进入伏波时写入完整上下文、禁用控制并请求正确场景。
- 海图返回测试：合法上下文恢复船位/朝向/阶段/月相；坏上下文使用安全回退点。
- 岛屿场景契约：码头离岛触发区存在、位于活动范围且不与钓鱼触发中心重合。
- 岛屿交互测试：进入/离开触发区正确显示和隐藏提示；按键后请求海图场景；失败时恢复控制。
- 完整往返运行测试：海图伏波入口 → 岛屿码头 → 离岛 → 海图原船位，应用进程持续存活。
- 既有海图、伏波、钓鱼、鼓令、宿主和存档测试继续通过。

## Non-goals

- 不增加敌人、战斗、额外 NPC 或第三个小游戏。
- 不改动伏波古岭在海图上的美术、坐标、碰撞轮廓和入口水域。
- 不修改主流程存档版本。
- 不接入其他 14 个占位地点。
