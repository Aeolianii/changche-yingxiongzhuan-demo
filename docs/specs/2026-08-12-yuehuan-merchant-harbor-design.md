# 月环商港与全局仓库设计规格

- Status: approved
- Date: 2026-08-12

本规格采用 [经济、仓库与月环商港设计](../design/economy-merchant-harbor.md) 的全部规则。架构分为四个边界：只读 `ItemCatalog` 维护物品、图纸和船型静态数据；`EconomyState` 负责可验证的持久状态；`TradeService` 执行原子买卖、图纸购买和造船；商港与物品栏 UI 只调用服务并渲染结果。`GameState` 负责跨场景共享和版本化存档，不让具体场景保存各自的库存副本。

月环商港是独立 UI 场景，通过一次性旅行上下文保存海图船位、朝向、探索阶段和月相。商港返回时由海图消费上下文恢复状态。全局物品栏由唯一的 `ExplorationHUD` 持有，在所有探索场景复用同一经济快照。

所有状态变更使用结果字典返回 `ok`、`reason` 和变更后快照。服务先校验 ID、数量、库存、军饷、图纸和舰队上限，再一次性提交；失败不产生部分扣款。自动化测试覆盖每条状态转移、存档迁移和场景往返；运行时测试覆盖真实按钮与输入阻断；截图用于 1344×896 布局验收。

首版明确不包含商人委托、收藏兑换、装备买卖、维修和战棋编队重做。
